# 输出与风险契约

报告先给模式、覆盖、最终条件名单数量与限制。包含：研究快照；原报告主张审计；主线及证据；最终条件名单；等待/排除及待研究线索；组合风险；下一核验与归档。最终可以为空，不能凑数。

最终表字段：代码/名称、A/B/C、状态、核心证据、估值或事件情景空间、行情锚、入场/禁入、失效/退出、期限、风险预算、来源/旧记录。证据不足不写“试仓1/3”。账户未知标未适配，不执行交易。

## 操作条件

有完整数据时实际计算价格、日期和缓冲；没数据保留变量并禁入，不仅写“回踩不破”：

- P0：最新有效收盘价与日期，未复权。
- L：完整K线和公司行动核验后的结构失效锚。
- U：A估值上限或B/C有依据的事件情景上限。
- V：同时间可比成交量/额，不拿早盘量比较完整日量。
- valid_until：方案失效时点。

盘前只生成方案，开盘后检查实际价格、量价、可成交性和新公告。超允许价、破失效锚、事件取消或风险不足则不参与。A/B/C分别包含经营估值失效、事件窗口结束、重组路径失败；技术风险退出单列。次日需重评，方案不无限有效。“三卖”“第五层”未明确定义不作可执行退出规则，“天地板”不能假定可成交清仓。

## 仓位

r_i为该股可承受损失占净资产比例，d_i为入场至失效价相对损失，s_i为成本滑点/合理跳空压力缓冲：

\[
w_i\le\min\left(\frac{r_i}{d_i+s_i},w_{liquidity},w_{stock},w_{theme\_remaining}\right)
\]

这是情景预算，不能保证实际亏损不超过r_i。A股T+1、跌停和停牌应估计更差情景，不假定止损成交；相关主题合并压力测试。缺失参数不报精确仓位，无个人参数可给清楚的假设示例：风险预算0.25%净资产、不利损失含缓冲10%，上限2.5%净资产，再受更低组合/流动性限制。比例分母必须明确。“1/3”仅可指已计算的单股计划仓位，无强制下限。

## 归档

manifest.json：模式/run_id/规则版本/截止/分市场asof/来源版本/覆盖/工具调用数及故障/限制/产物。不记录密钥。candidates.json保存全部候选而非赢家，每条含：

```json
{"ticker":null,"name":"待确认名称","species":"A","stage":"lead","channels":["user_report"],"thesis":"待核验命题","evidence":[],"missing":["identity","business_exposure"],"baseline_record_id":null,"decision":"待研究，尚未进入条件操作名单","entry":null,"invalidation":null,"exit":null,"risk_budget":null,"valid_until":null,"next_checks":["唯一解析代码与业务"]}
```

ticker空不能进入逐股判断。unknown/null不能通过门。conditional_ready必须有核验身份状态、关键证据、A估值/B或C情景、行情锚、入场禁入退出有效期、风险计算参数或清楚的账户未适配标记；没有可计算风险的状态只能wait。保存跨期状态变化。个股深研另按analyze-a-shares归档，扫描不能替代历史。
