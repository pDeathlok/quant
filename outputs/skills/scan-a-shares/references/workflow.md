# 扫描工作流

## 时点与数据

保存带时区analysis_cutoff、分市场market_asof、planned_session、horizon、rule_version和run_id。历史扫描只允许available_at不晚于截止；报告期、访问时间不是首次可得时间。历史身份/状态/成分及复权因子应匹配当时。

先发现项目基础名单、交易日历、行情层和研究档案，通过已有加载函数复用配置，不读取回显.env。quant项目参考入口（替换证券与时间，先检查帮助）：

```bash
PYTHONPATH=src python -m quant.research.a_share_history context --ticker 600519.SH --before 2026-10-07T18:00:00+08:00 --output /tmp/scan_history_600519.json
PYTHONPATH=src python -m quant.research.a_share_skill_data --ticker 600519.SH --cutoff 2026-10-07T18:00:00+08:00 --kind stock --bars 250 --output /tmp/scan_bars_600519.json
```

完整读取历史输出，提取旧论点和证伪条件。项目日线未复权、量为手，区间收益需处理公司行动，未经处理不能作为可比排名。正式数据库异常不得静默换镜像；显式备份需披露滞后与版本。无模块时记录未复用及降级路径。

外部优先当次实际加载的mx-ds-mcp；先读schema，筛选/金融数据/板块工具做结构化发现，公告搜索找原文，新闻只作线索。查询写日期不保证返回满足日期，检查返回列名、窗口、股票类型和元数据。500上限无分页时按市场/行业/代码段分片，检查重复和遗漏。

## 覆盖

分别输出 universe_count（范围内股票数）、observed_count（独立证券）、market_data_count（同步完整行情）、excluded_count（分原因且交集去重）、eligible_count、各通道初筛/合并/研究/条件名单数，以及缺失市场/日期/字段/分页和影响。覆盖比例明确分母；行情覆盖不等于公告和基本面逐股覆盖。Top20不能反推基数，新股发行价至现价涨幅不能当作可比20日收益。

## 多通道候选

候选并集：产业政策与业务敞口、经营改善与估值预期差、新增事件、量价/行业相对强弱。分别报告通道范围，禁止只扫热门主题便称全市场。环境结合趋势、涨跌分布、行业广度、成交额相对自身历史、波动和流动性；固定1.6万亿、环境负减半等仅为未经验证的原规则。海外利率/原油不直接推出国内行业普遍受益。

主线写独立证据与反证，不强制两条或六条。五层按行业适配材料/工具设备/部件/系统整机/应用，同股多层需说明收入利润敞口；不强制固定轮动。海外映射逐项检查驱动、产品客户关联、国内利润、竞争估值、已计价程度；未经核验供应关系不得写确认受益。

## 分类研究

- A：真实需求、业务关联、经营KPI→利润现金流、治理与财务、估值及隐含预期、点时量价。报价区分规格、现货合约和样本；无报价改用适用订单/交付/留存/审批指标。
- B：可打开的新增催化、公布/事件时间、直接关联、相对旧事件的新信息、已计价程度、情景空间、窗口和退出。旧行情涨幅不是未来空间，无新增事件观察。
- C：异常→控制权→交易方案→程序→完成→价值创造分别检验。信源等级与预测强度分开，无校准不报成功率；公开方案仍查融资、稀释、终止及不利情景，传闻不作参与依据。

关键证据含claim_id、source、url、data_period、published_at、available_at、accessed_at、unit、status。估算给公式，推断给反证。无来源“满分”“龙头”“头号”降级。

## 名单门与排序

| 状态 | 门槛与动作 |
|---|---|
| lead | 只有映射/主题/异常；待研究，不能试仓 |
| research_candidate | 身份与关联已核验，关键研究有缺口 |
| wait | 基本面/事件研究完成，但入场未满足或执行受限；列等待与失效 |
| conditional_ready | 身份状态、关键证据、A估值/B或C情景、同步行情锚、退出、期限、风险预算完整；盘中触发尚待发生，不称成交 |
| exclude | 已证伪/红线/用户规则排除/明确执行障碍；区分临时和永久 |

未知风险待核验，不编排除理由。先证据与风险门，后比较预期差、空间、估值、量价和流动性。未经验证分数只称研究优先级，不能称胜率或预期收益模型。允许并列和最终为空。

## 回测与复盘

参数写窗口、单位、分母、来源、验证状态；资金z-score注明方法，政策去转载，月环比考虑季节性与有效样本。改规则建新版本不改旧信号。

记录所有失败、未触发、买不到、停牌和规则外；研究的1/5/20/60日评估窗口与真实期限分开。回测纳入费用、滑点、T+1、涨跌停、停牌、退市、公司行动和资金占用；可见价格不代表成交可得。滚动样本外、多市场阶段，比较简单行业动量/基准和模块消融。胜率配盈亏、净收益、回撤、尾部和容量；事后涨幅榜只查漏，不证明预测有效。
