# 持仓股次日涨跌事件概率

用户将目标明确为持仓分析与正T/反T参考：发现少量高确定性涨跌事件，优先检验概率模型效果，不要求每日交易，不以固定卖法收益选优。继续使用当日收盘及全天量价作为 T 日截面代理。

新增概率模块 `src/quant/research/holding_event_probability.py`、训练入口 `scripts/research/train_holding_event_probability.py` 与合同测试 `tests/test_holding_event_probability.py`。

八个标签：次日最高价相对 T 收盘达到 +1/+2/+3%，次日最低价达到 -1/-2/-3%，次日收盘达到 +1%/-1%。其中高低点事件不互斥；不推断次日高低点先后，也不直接输出已验证正T/反T执行指令。缺失标签不填成否。

使用完整历史策略并集，不执行原有买入可执行性筛选，以适应已持仓股票。测试三组特征：T-1；T-1 加原 T 日量价；再加新的 T 日价格形态、跳空回补、量价和波动异常交互。所有列显式按前缀准入，拒绝目标列。

2024 拟合，2025H1 概率校准，2025H2 选择高置信阈值及特征组，2026 确认。此前已见过 2026，明确为研究确认而非全新盲测。另以预设扩展训练验证其稳定性（若初轮不存在支持信号，不强制创造信号）。

核心指标：高置信 precision、recall、覆盖率、相对基础发生率 lift、Brier、PR-AUC、ROC-AUC、概率校准误差。阈值 0.5/0.6/0.7/0.75/0.8/0.85/0.9/0.95。高置信候选需验证 precision>=80%、按连续5日区块重采样的 precision 90%区间下沿>=70%、lift>=1.2、至少50条且20个日期；选择满足要求者覆盖率最高的组合。它是探索筛选标准，不是多重搜索调整后的概率保证。

不按测试结果再选阈值。没有合格组合时输出证据不足，仍保存全部指标和预测概率。验证命令：`PYTHONPATH=src /Users/didi/miniforge3/bin/python -m pytest -q tests/test_holding_event_probability.py tests/test_tail_overnight.py tests/test_tail_overnight_selection.py`。
