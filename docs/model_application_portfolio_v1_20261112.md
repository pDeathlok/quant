# 模型应用组合 v1：双目标验收与执行迭代

> 历史阶段记录：下文保留候选验收时的状态。后续默认组合接入与新样本结论见 [第二轮验收记录](model_application_iteration_v2_20261112.md)；当前生效配置以 `configs/strategies/application_portfolio.json` 为准。

2026-11-12。结论：确定 **25% 三模型融合 + 25% 原模型分/路径融合 + 50% 低波动结合** 为下一版研究候选，已完成模型固化、独立推理和成本压力测试。历史回放满足收益更高、最大回撤更低。当前状态是研究候选及每日影子输出，尚未替换默认线上排序。

## 固定方案

| 独立资金份额 | 排序方式 | 作用 |
|---|---|---|
| 25% | (原模型分 + 路径模型百分位 + RankNet 百分位) / 3 | 同时利用收益排序与路径信息 |
| 25% | (原模型分 + 路径模型百分位) / 2 | 提高路径质量的影响 |
| 50% | 0.8 × 原模型分 + 0.2 × 低波动分 | 降低高波动候选的排序优势 |

原模型分：左侧为现有 left_side_ranknet_v6 融合分，右侧为 right_side_unified_canonical_v2 原始预测经过官方冻结 CDF 归一化的分数。研究没有叠加线上 ETF 加分。辅助模型采用 2026 折已冻结的 path_boundary 和 rank 模型，各侧分别计算当日横截面百分位。低波动分等于 1 减去当日同侧 volatility_20d 百分位，缺失时为 0.5。

path_boundary 在训练时排除了 MFE 距离 +5% 不足 0.5 个百分点、或者 MAE 距离 -3% 不足 0.5 个百分点的边界样本。推理时不按未来结果筛选候选。

三路各自持有现金和股票，按初始资金份额独立复利，不每日重新分配资金。每路最多持有 120 只，每天最多尝试新开 20 只，下一交易日收盘买入，持有 5 个市场交易日后收盘卖出。单路内部同股左右侧重叠时取右侧。跨路允许同股，各路成本和资金单独计入。

因此，不能把三路分数按 25/25/50 加成一个总分后只取一个 Top20，那会改变已验证的策略。每日输出保留三路完整优先队列，已有持仓应先排除，再决定新开仓数量。

## 历史验收

以下收益均为区间累计净收益，最大回撤按正数表示。默认买卖合计成本 20bp，使用相同候选池、交易日、执行约束及盯市账户。

| 评估口径 | 基线收益 | 组合收益 | 基线最大回撤 | 组合最大回撤 | 双优 |
|---|---:|---:|---:|---:|---|
| 2025 下半年，按当时验证段选权重 | 11.05% | 19.36% | 6.94% | 5.72% | 是 |
| 2026 至 9 月 3 日，研究模型分 | -19.89% | -11.66% | 32.66% | 25.29% | 是 |
| 2026 至 9 月 3 日，生产模型分回放 | -18.94% | -15.88% | 31.13% | 25.39% | 是 |

第三行使用真实生产模型产物，但输入仍是研究候选池和历史特征，并非完整线上系统净值。组合较基线提高收益 3.06 个百分点，降低最大回撤 5.75 个百分点。平均仓位约 79.03%，基线约 79.55%。2026 年仍有明显亏损。

权重选择在每折自己的历史验证段完成，五种策略的权重以 25% 为步长，共 65 组多策略组合。先要求验证段收益和回撤均优于基线，再最大化“收益改善、回撤下降”两者中的较小值。2025 下半年选出的是 75% 三模型融合 + 25% 持有 10 日，最终的 25/25/50 由 2025 年 10—12 月验证段选出。第一行验证的是顺序选权重流程，不能归为最终固定权重的同口径回测。

本轮建立选择规则时已经知道此前应用实验的大体结果，历史数据已反复研究，不能将本轮称为全新的独立留出验证。

## 已完成的迭代与核验

- 成本迭代：10、20、40、60bp × 三个评估口径，共 12 组，全部保持收益和回撤双优。生产模型分在 60bp 下组合收益 -24.08%、最大回撤 31.11%，基线分别为 -26.83%、36.53%。
- 账户迭代：现金、费用、成交与未退出持仓分开计量，买入不可成交则跳过，卖出不可成交则延后。44 个压力情景子账户通过独立盈亏重建，最大误差约 1.12e-12。未退出持仓保留最后价格估值，并另做全部归零压力测试，生产口径归零后组合 -16.25%、基线 -20.16%。归零压力值是终值收益，不等于完整路径回撤压力测试。
- 推理迭代：四个辅助模型精确压缩，左侧使用 71/65 个特征，右侧使用 61/52 个特征。所有历史预测与压缩前逐值相同。
- 排序核验：三路各 167,060 条历史候选，与研究实现的分数、同股去重、排序完全一致。独立资金份额聚合后的逐日净值也一致。
- 命令行核验：2026-08-21 共 1,787 条左右侧输入、1,745 只去重股票，输出 5,235 条分路排名，与完整历史回放相同。
- 每日入口实际运行：已完成 2026-11-11 快照，553 条左右侧候选、549 只去重股票，生成三路共 1,647 条排名。缺失的辅助特征由本地数据补齐，结果位于 `reports/research/dual_objective_portfolio_v1/shadow/20261111/`。这是最新快照的影子输出，尚无未来收益验证。
- 特征生成迭代：修复精简特征集合触发的派生特征依赖缺失，生成器只计算被请求的派生项，并自动补齐其底层输入。完整模型、只请求派生项、最小特征集合、冻结源缓存及并行结果均作核验。
- 回归测试：19 项通过，覆盖资金份额漂移、日历错位、同股重叠、未来数据不影响过去、输入校验、交易账本和生产特征入口。

分块重采样采用配对的 10 交易日循环区块，共 2,000 次。生产模型分口径的收益改善 95% 区间为 **-7.26 至 +10.54 个百分点**，回撤改善区间为 **-1.32 至 +9.57 个百分点**。两者均跨零，而且没有对策略搜索作多重比较校正，因此尚不能认定统计上稳定双优。

三路生产回放的日收益相关性约为 0.79—0.96，分散程度有限。当前研究使用可分割股数，没有验证整手、最低佣金、成交容量，也没有完整的盘中队列模型。

## 产物和复现

- 配置：`configs/releases/application_portfolio_v1.json`
- 冻结模型与执行约定：`models/candidates/application_portfolio_v1/manifest.json`
- 选择、验收、成本、统计区间与校验：`reports/research/dual_objective_portfolio_v1/`
- 推理模块：`src/quant/ml/application_portfolio.py`
- 运行入口：`scripts/run_application_portfolio.py`

```bash
PYTHONPATH=src:. python scripts/research/select_dual_objective_portfolio.py
PYTHONPATH=src:. python scripts/research/stress_dual_objective_portfolio.py
PYTHONPATH=src:. python scripts/research/stage_application_portfolio.py
PYTHONPATH=src:. python -m pytest -q tests/test_application_portfolio.py tests/test_model_application_research.py tests/test_sample_label_research.py tests/test_rank_feature_snapshot.py tests/test_left_ranknet_production.py
```

每日影子输出复用本地已发布的原模型分，补齐辅助模型特征，不抓取外部数据。示例使用当前已有的 2026-11-11 信号快照：

```bash
PYTHONPATH=src:. python scripts/run_application_portfolio.py --date 2026-11-11 --latest --workers 4
```

输出为带权重的三路优先队列、无标签输入及校验清单，不包含账户持仓、委托数量或交易指令。模型版本、输入日期或来源在计算中变化时会拒绝输出。

下一轮应保持这组权重冻结，用新的成熟样本继续比较基线，核验整手与最低佣金、完整生产候选池及新增日期特征一致性。只有形成新的双优证据，才适合升级为默认线上组合。当前默认选择器保持原版本。
