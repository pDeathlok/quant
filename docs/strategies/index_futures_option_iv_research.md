# Tushare期权历史与自建隐波研究（2026-11-15）

数据已补齐，自建隐波已进入固定与滚动策略对照。当前没有足够证据整体替换原方案或QVIX：自建方差在持续账户有改善，近平值隐波在部分滚动情景有改善，但完整窗口和费用/资金敏感性仍不稳定。默认候选保持不变。

## 数据与方法

- 下载中金所期权日线864,798条、上交所期权日线874,486条；合约与日线分页到空页，检查重复、日期和合约有效期。Shibor共2,932条。原始页和SHA256保留。
- MO（IM对应期权）上市以来1040个交易日、IO 1665日、HO 940日均无整日缺失。2026截至11月6日均有203天行情；MO为58,416条。原QVIX中证1000同年只有11条非空记录。
- 用IO/MO/HO构建日线收盘版30日方差代理和30日近平值隐波。收盘价不是同步买卖报价，不能称为精确复刻标准VIX。结算价仅作价格敏感性诊断。
- ETF历史也已保存，但最新静态行权价可能经历调整，无法安全回套更早日期。因此暂不用于自建隐波。IC在自建分支中使用共同IO因子、自身隐波缺失；原QVIX仍保留500ETF。
- 期限7–120天、看涨看跌平价检查、成交与持仓要求、行权价覆盖规则均在回测前固定。只在有效期限夹住30天时按总方差插值，不外推、不前填；利率使用当日Shibor期限插值代理。
- 2026年MO有153天通过方差30日计算、160天通过近平值30日计算。近平值收盘/结算隐波差的95%分位为0.141个波动率点；方差法为0.828点。后者对远端价格更敏感。

原始行情齐全不等于模型每天都有新隐波特征。额外滞后一日、历史分位预热和连续5日变化要求进一步降低覆盖。2026年IM预测中，方差分支约61.9%、近平值分支约43.6%回退原QVIX。因此结果是带明确回退的组合，不能全部归功于新指标。

## 固定研究设计

50万元、最多一手、允许多空、不补资。保留原85因子、原5日入场标签、mean5保护退出、状态期限20/10/5、资金储备和全局入场日历。所有模型季度重训，36个月已成熟历史、12个月权重半衰期；参数、概率门槛和风险门槛均未搜索。

五组方案：原状态期限、冻结QVIX、原因子＋自建方差、原因子＋自建近平值、QVIX中仅替换IM自身为MO方差。后三组均93项因子，保持新增维度相同。固定政策先比较；滚动仍只在原4种政策间，按历史多起点、当前实际权益和原切换门槛选择。

完成1660条账户、4760个窗口；664条原方案/QVIX对照账本逐日一致；180条Python/C++执行路径持仓、现金一致，最大现金差0元。

## 关键反证：较低费用没有保证更稳

2026年初、仍为25%保证金，但费用改为3bps：固定/重选QVIX和方差分支均为-14.53%收益、30.80%回撤；滚动近平值为-0.44%、23.09%。因此6bps/25%下的改善不能推广为“高保证金已解决”。

一处可核对的原因是2026-07-28的账户边界：3bps的QVIX账户权益503,050元，超过当日信号最低资金（含储备）500,448元，买入IF并在次日亏18,821元；6bps账户权益499,381元，低于其最低资金500,861元，开仓被资金约束拒绝。后续权益和标的选择继续分化。不是费用提高产生收益，而是一手容量下几千元差异改变了路径。

四组费用/保证金交叉验证全部保留，未针对这笔已知亏损修改规则。完整月度网格与前轮保持一致，为3bps/15%和6bps/25%；另外两组为年度交叉验证。

## 当前结论

数据基础已明显改善；自建方差值得作为持续账户和风险辅助方向保留，自建近平值值得继续检验其与历史重选的交互。当前没有全场景最优方案，不升级默认，不自动选取各年份赢家。下一步优先验证期限缺口和特征连续性造成的回退，以及用真正新增期间检验稳定性；不按2026已知损失反调门槛。
