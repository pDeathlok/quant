# 可转债不限期持仓网格迭代记录

## 目标

在低位网格策略基础上，允许持仓时间不受限制。买入后不因为标的不再满足入场低位条件就卖出，而是只在明确退出条件出现时卖出。评估日频、周频、月频再平衡，并尝试向 10% 年化目标靠近。

## 新增机制

新增类：

- `HoldingGridConfig`
- `HoldingGridStrategy`
- `backtest_holding_grid`

入场仍使用低位确认：

- 价格低
- 溢价率低
- 双低值低
- 处于 252 日低位
- 从 252 日高位有一定回撤
- 20 日动量不能太差

持仓逻辑：

- 已持仓标的可以继续持有，即使不再满足入场条件。
- 仅在强赎风险、价格过高、溢价过高、双低值过高、历史分位过热等退出条件出现时卖出。
- 支持 `max_holdings`，避免不限期持仓扩散成几十只小仓位。
- 支持 daily、weekly、monthly 再平衡。

## 关键结论

不限期持仓显著提高收益，但 10% 年化目标尚未达到。

2015-2026 最好结果：

- 变体：`hold_aggressive_low`
- 再平衡：weekly
- 总收益：36.99%
- 年化收益：2.92%
- 最大回撤：-20.90%
- 平均仓位：44.24%

2020-2026 最好结果：

- 变体：`hold_aggressive_low`
- 再平衡：weekly
- 总收益：40.08%
- 年化收益：5.67%
- 最大回撤：-24.95%
- 平均仓位：78.00%

2024-2026 最好结果：

- 变体：`hold_core_fast_exit`
- 再平衡：monthly
- 总收益：17.65%
- 年化收益：7.44%
- 最大回撤：-10.98%
- Sharpe：0.98
- 平均仓位：50.40%

## 推荐观察版本

### hold_core_fast_exit monthly

更适合近两三年：

- 月粒度再平衡，交易次数少。
- 2024-2026 年化 7.44%，最大回撤 -10.98%。
- 平均仓位约 50%，符合“低位才明显建仓”的方向。

### hold_aggressive_low weekly

收益弹性最高，但风险偏高：

- 2020-2026 年化 5.67%，最大回撤 -24.95%。
- 2024-2026 年化 6.81%，最大回撤 -14.22%。
- 平均仓位长期偏高，不完全符合“确定性低位才大幅建仓”的风险偏好。

## 对 10% 年化目标的判断

当前规则体系下，10% 年化没有达到。主要原因：

- 2015-2019 低位网格机会少，长期空仓拖低年化。
- 低位可转债收益主要来自市场修复阶段，不是持续稳定收益源。
- 提高仓位和放宽入场能提升收益，但回撤迅速放大到 20% 以上。
- 近两三年最佳结果约 7.44%，距离 10% 仍有差距。

要继续靠近 10%，需要引入新的收益源或状态判断：

- 全市场可转债趋势过滤：市场仍在急跌时延迟建仓，企稳后提高仓位。
- 正股质量/动量过滤：只买低位转债中正股趋势改善的标的。
- 行业/主题过滤：避免弱行业低位陷阱。
- 机器学习只作为排序辅助，不直接替代规则。
- 若坚持 10% 年化，可能需要接受更高回撤或引入杠杆/权益仓位增强。

## 市场状态过滤补充

新增市场状态特征：

- `market_median_double_low`
- `market_price_position_252`
- `market_trend_20d`

新增两类入场控制：

- `scale_downtrend`: 市场 20 日趋势向下时，新开仓仓位打折。
- `block_downtrend`: 市场 20 日趋势向下时，停止新增仓位，只管理已有持仓。

定向结果：

2024-2026：

- `hold_core_market_block monthly`: 年化 6.28%，最大回撤 -4.94%，平均仓位 39.72%。
- `hold_core_market_scaled monthly`: 年化 6.22%，最大回撤 -10.23%，平均仓位 45.70%。

2020-2026：

- `hold_core_market_scaled daily`: 年化 3.98%，最大回撤 -16.34%。
- `hold_core_market_block daily`: 年化 2.67%，最大回撤 -18.82%。

结论：

- 市场状态过滤对降低近期回撤有效，尤其月频停止新增仓位。
- 但它降低了暴露，也降低了收益弹性。
- 市场过滤更适合做风控层，不是把年化推到 10% 的主要收益来源。

## 下一轮方向

若继续以 10% 年化为目标，单纯调低位和网格参数的边际收益已经不高。下一轮应该加入正股/行业侧的进攻确认：

- 使用 Tushare 正股日线，计算正股 20/60 日动量、波动、均线斜率。
- 仅在正股趋势改善时提高可转债仓位。
- 对全市场状态采用 `block_downtrend monthly` 作为风控底座。
- 将候选从纯双低扩展为“低位转债 + 正股修复 + 行业非弱势”。
