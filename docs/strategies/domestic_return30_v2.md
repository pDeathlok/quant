# V2：五篮子核心＋较高风险预算

与V1独立保留，配置为`configs/strategies/domestic_return30_v2.json`。本版本是已经观察历史上筛选出的研究候选，不是盲测或生产部署。

核心目标篮子：BYD20%、宽基20%（沪深300/中证500各10%）、黄金20%、国债20%、证券0%、红利20%。各篮子目标0—20%，无杠杆、无做空；证券权重为零符合用户允许的资产类别零仓位。五篮子满配目标合计100%。

每收盘用过去63日各资产收益与当日核心权重估计组合年化波动，乘min(1,22%/该波动)缩放全部投资仓位，余下为现金。月度21交易日检查、3个百分点死区；下一开盘执行共享现金整手账户。超过23%实际篮子占比请求减仓，非月度检查日请求减至22.5%，允许盘中短暂漂移。交易磨损、基金分红、股税、参与率与V1相同。

2014-08-01至2026-10-12基础年化11.02%、回撤26.74%；2018起10.35%/18.04%；2024起13.44%/10.78%。严重/极端成本完整期分别10.60%/27.86%、10.57%/28.07%；1000万元10.03%/25.79%。所有上述完整期/2018期回撤低于30%，但这不是实盘30%回撤保证。

近优风险参数：18%波动预算，基础年化11.01%、回撤23.33%，与22%的收益差只有约0.0028个百分点（0.28基点）每年，不能声称22%显著更优。18%在严重/极端磨损下年化10.83%/10.90%、回撤23.40%/23.70%；1000万元9.83%/23.75%。两个参数均是同一预设候选集合，不是结果后新增候选。

候选选择：冻结64专家、70候选，明确根据已观察完整期在四成本容量情景、完整/2018区间回撤均<=30%的候选中按基础完整期净CAGR排序。另行执行过去3完整年度选型流程，净年化9.18%、回撤21.21%，未超过V1。不能将固定候选11.02%解释成年度过去数据选型的收益。

复现：目标缓存`reports/research/domestic_return30_v2_20261013/expert_targets.npz`中的`nosec_blend_vol22`，近优为`nosec_blend_vol18`；报告同目录`report.md`，运行`PYTHONPATH=src OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/research/run_domestic_return30.py`。源哈希、独立前缀、V1精确重放、成本压力保存在manifest及账本；20项专项测试通过。前向验证应在冻结参数后使用未参与设计的新数据，后续变化另建版本，不覆盖V1/V2记录。
