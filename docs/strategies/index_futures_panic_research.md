# 股指恐慌因子研究记录（2026-11-15）

QVIX 已接入股指研究版，保留此前状态期限方案作对照。新增因子有增量，但尚未升级默认候选：2026年部分起点仍亏损，期权源有断档，历史已反复用于研究，不能称为新的OOT验证。

## 数据来源

- AKShare `index_option_50etf_qvix`、`index_option_300etf_qvix`、`index_option_500etf_qvix`、`index_option_1000index_qvix` 分别对应 IH、IF、IC、IM；另保留300股指、50股指、创业板、科创板QVIX供数据质量核对。本轮共同指标是50ETF QVIX。
- 下载的50/300/500ETF QVIX从2015-02-09、2019-12-23、2022-09-19开始，均延续到2026-11-13。1000股指QVIX自2022-07-22开始，最后非空为2026-03-13，且2026仅11条非空记录，不能把日期范围当完整覆盖。
- 上游2026-11-02存在冲突重复日期，两条全部隔离；非交易日通过现货交易日历排除。未自行纠正或前填。价格、预测和标签统一截止2026-11-06。
- Tushare `opt_basic` 的SSE/CFFEX只读探测成功，每个市场取1000条，不是完整下载；2026-11-06 `opt_daily` 返回SSE704条、CFFEX760条。可继续补建自己的期权隐波，但本轮没有把期权收盘价当报价中间价直接冒充标准VIX。

## 固定假设与评估

原方案为固定政策或季度重选、季度多空模型重训、入场状态锁定20/10/5日上限、原mean5与资金保护退出。50万元、最多一手、固定全局入场日历、无补资。过去36个月成熟标签、12个月半衰期，训练期内插补和标准化，保持原LR/Ridge参数与入场门槛。

新增三个研究分支：QVIX、价格压力、两者同时加入；未搜索阈值或改变退出。QVIX采用共同/自身历史分位、5日变化、隐含减实际波动代理、缺失标记；在信号日上额外滞后一个交易日。价格压力由下行波动、60日回撤、放量下跌的历史分位等权组成，是价格代理而非期权隐含波动率。

完成1328条账户、3808个统计窗口，覆盖2022–2026月度起点、年初相邻交易日起点、单年、累计至2026-11-06、122/244日等长窗口、持续账户。原方案332条账本逐日复现通过；144条Python/C++路径现金与持仓一致，最大现金差0元。所有测试账户未触发模拟强平，不构成未来或盘中偿付保证。

每年重新以50万启动，单年扣费收益 / 最大回撤：

|---|---:|---:|

| 2023 | -0.21% / 13.76% | -0.21% / 13.76% |
| 2024 | 56.07% / 7.73% | 55.17% / 7.73% |
| 2025 | 47.81% / 7.14% | 59.68% / 6.74% |
| 2026截至11月6日 | -5.65% / 27.10% | 3.06% / 18.30% |

47个月度起点的244日等长窗口：

| 方案 | 收益中位 | 最差收益 | 最大回撤 | 空仓中位 |
|---|---:|---:|---:|---:|
| 原固定 | 28.97% | -1.62% | 25.57% | 75.41% |

这些最大回撤来自等长窗口集合，不是策略的统一风险上限。全部月度/相邻日起点累计至终点，固定QVIX最大回撤24.86%，重选QVIX18.30%。

2026年10个月度起点累计至终点：固定QVIX收益中位-1.17%，原固定-3.72%；盈利起点从1/10升至5/10，但仍有一半起点未盈利。不能以1月初启动的3.06%收益代替全起点评估。

2025年启动并持续运行：QVIX累计收益97.04%、累计回撤13.31%，原方案86.32%、13.89%。其中2026单年QVIX收益23.40%，低于原方案26.05%；年内回撤13.31%，略低于13.89%。年度实际期初权益不同，这和2026重新以50万启动不是同一账户。

基础情景3bps/15%保证金下，244日固定QVIX收益中位44.43%，原固定34.00%；但最差收益3.63%，低于原固定6.27%，最大回撤同为22.24%。并非所有维度均改善。

单独价格压力的改善较弱；联合分支高保证金244日最大回撤31.49%，高于原方案25.57%。2025持续账户的2026联合分支收益-1.82%、回撤26.72%，因此不因因子更多而采用联合方案。

## 当前判断与后续边界

优先保留“原状态期限＋QVIX”作为新增研究候选，固定和重选均保留；默认仍为原候选。先补齐期权数据质量，再做真正新增期间验证，不能按已知2026亏损调参数。本轮只改入场因子，未证明恐慌退出或抄底规则有效。
