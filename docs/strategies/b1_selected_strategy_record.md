# B1 正式策略档案

## 1. 文档目的

## 2. B1 原始信号

B1 是一个偏超跌反弹的候选信号。当前正式版本已经删除了早期的成交量条件。

当前 B1 候选池使用的核心条件：

```text
当日涨跌幅在 -2% 到 +2% 之间
当日振幅 < 7%
BBI > MA60
KDJ J < 0
排除 ST、退市相关股票
不再要求“当日成交量大于上一日成交量”
```

删除成交量条件的原因：

```text
早期 B1 要求当日成交量大于上一日成交量。
后续分析认为这个条件会过早排除一部分缩量企稳的机会。
因此正式版本中将成交量放大从硬条件中删除，量价状态改为后续分析和辅助过滤项。
```

## 3. 买入逻辑

正式策略不再使用“每日排序买前 XX%”。

原因：

```text
真实交易中不一定每天都要交易。
如果当天没有足够好的机会，策略应该允许空仓。
因此买入规则改为固定阈值：
只要模型预测值达到阈值就买；
没有达到阈值就不买。
```

买入执行口径：

```text
T 日出现 B1 信号并满足模型阈值
T+1 开盘买入
```

## 4. 模型预测值含义

当前策略使用 3 个模型输出：

| 字段 | 含义 | 当前用途 |
|---|---|---|
| `pred_up8_es` | 预测 T+1 开盘后，未来区间最高价达到一定上涨幅度的概率，当前使用 8% 上涨模型 | 判断上涨弹性 |
| `pred_up10` | 预测 T+1 开盘后，未来区间最高价达到 10% 上涨幅度的概率 | 参与综合分研究，当前正式策略不直接设阈值 |
| `pred_down3_es` | 预测 T+1 开盘后，未来区间最低价向下触发较深回撤的概率，当前使用 3% 下跌风险模型 | 控制先跌破止损的风险 |

关键结论：

```text
只提高 pred_up8_es 能提高单笔平均收益，但对胜率改善有限。
真正改善胜率和回撤的是限制 pred_down3_es。
原因是“未来有上涨空间”和“买入后不会先跌破止损”不是同一件事。
```

## 5. 正式保留策略

### 5.1 B1 稳健版

策略 ID：

```text
b1_stable
```

买入条件：

```text
B1 原始信号成立
pred_up8_es >= 0.55
pred_down3_es <= 0.55
```

卖出规则：

```text
T+1 开盘买入
固定止损 1.5%
上涨达到 4% 后启动回撤止盈
从最高点回撤 2% 卖出
最晚 T+7 到期卖出
```

策略定位：

```text
作为当前主策略。
目标是降低最大回撤，同时保留相对足够的交易数量。
```

### 5.2 B1 进攻版

策略 ID：

```text
b1_aggressive
```

买入条件：

```text
B1 原始信号成立
pred_up8_es >= 0.65
pred_down3_es <= 0.50
```

卖出规则：

```text
T+1 开盘买入
固定止损 1.5%
上涨达到 5% 后启动回撤止盈
从最高点回撤 2% 卖出
最晚 T+9 到期卖出
```

策略定位：

```text
作为高质量信号策略保留。
交易机会明显少于稳健版，但单笔收益和盈亏比更高。
不建议单独作为唯一主策略。
```

## 6. 样本外回测表现

回测区间：

```text
样本外：2025-01-01 以后
候选池：删除成交量条件后的 B1 候选池
买入：T+1 开盘
卖出：日线级别保守模拟；同日止损和止盈都触发时，默认止损优先
```

| 策略 | 交易数 | 平均单笔收益 | 中位数收益 | 胜率 | 日度夏普 | 最大回撤 | 盈亏比 | 止损率 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| B1 稳健版 | 2124 | 1.10% | -1.50% | 37.85% | 4.77 | -7.57% | 2.18 | 62.05% |
| B1 进攻版 | 312 | 1.71% | -1.50% | 38.78% | 5.02 | -9.09% | 2.86 | 61.22% |
| B1 旧基准 | 8484 | 0.98% | -2.00% | 35.23% | 5.92 | -14.35% | 1.76 | 64.57% |

结论：

```text
稳健版相对旧基准，最大回撤从 -14.35% 降到 -7.57%，胜率从 35.23% 提升到 37.85%。
进攻版平均收益和盈亏比更高，但样本外只有 312 笔，交易机会较少。
两者都应保留：稳健版作为主策略，进攻版作为更严格的机会策略。
```

## 7. 为什么不继续优先调 J 阈值

曾测试过更严格的 J 条件，例如：

```text
J < -10
J < -15
J < -20
连续多日 J < -5
```

主要结论：

```text
当前正式候选池采用 J<0，更严格的 J 更小条件可以略微提高单笔收益或胜率，但不能稳定降低回撤。
例如 J<-10 后胜率仅从 35.23% 提升到 36.14%，但最大回撤从 -14.35% 变差到 -17.33%。
因此，J 阈值不作为当前第一优先级优化方向。
```

## 8. 为什么强化 down3 风险过滤

`pred_down3_es` 是当前最有价值的过滤器。

单条件诊断结果：

```text
down3 <= 0.55：胜率 38.39%，最大回撤 -10.36%
down3 <= 0.50：胜率 40.63%
down3 <= 0.45：胜率 44.95%，但交易数明显下降
```

解释：

```text
B1 策略的主要亏损来自买入后快速触发止损。
上涨模型解决“有没有弹性”；
down3 风险模型解决“会不会先跌破止损”。
正式策略同时使用 up8 和 down3，是为了兼顾上涨空间和下跌风险。
```

## 9. 为什么调整卖出逻辑

旧基准使用：

```text
5% 目标后 2% 回撤止盈
2% 固定止损
T+9 到期
```

问题：

```text
止损交易比例高，中位数收益为 -2%。
策略靠少数较大盈利单覆盖大量小亏，胜率天然偏低。
```

改进后：

```text
稳健版将目标提前到 4%，止损收紧到 1.5%，到期缩短到 T+7。
进攻版保留 5% 目标，但同样使用 1.5% 止损。
```

结果：

```text
收紧止损显著降低最大回撤。
更早启动回撤止盈能提升胜率和资金曲线稳定性。
```

## 11. 已知风险

```text
1. 当前回测是日线级模拟，无法知道盘中先触发止损还是止盈；同日同时触发时采用止损优先的保守假设。
2. 稳健版在 2024 测试段仍出现较大回撤，说明市场阶段过滤仍需继续研究。
3. 进攻版样本外交易数较少，不能只看平均收益，需要持续观察样本扩展后的稳定性。
4. 当前没有纳入真实交易成本、滑点、涨跌停无法成交等完整实盘约束。
5. daily_basic 的估值字段存在天然缺失，模型侧使用中位数填充；后续做因子评价时应单独观察缺失率和覆盖率。
```

## 12. 后续迭代方向

优先级从高到低：

```text
1. 增加市场阶段过滤，避免系统性下跌阶段连续止损。
2. 增加行业集中度和单日最大信号数限制。
3. 增加真实交易成本、滑点、涨跌停成交约束。
4. 将根目录研究脚本中的 B1 引擎迁入 src/quant/routine/b1_engine.py。
5. 前端增加每日候选、持仓跟踪和策略开关。
```
