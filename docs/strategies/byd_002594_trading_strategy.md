# 比亚迪 002594.SZ 买卖点评分策略档案

更新时间：2026-06-16

## 策略定位

本策略专门服务比亚迪单票持仓管理，不做全市场选股。它把每日信号拆成三件事：

- `buy_score`：当前是否值得回补、加仓或重新建仓。
- `sell_score`：当前是否需要减仓、清仓或防守。
- `target_position_pct`：在单票账户里的建议目标仓位，用于重仓账户降风险。

策略使用前复权数据。所有均线、BBI、MACD、KDJ、ATR、回撤、收益和回测都基于 qfq 价格序列，避免除权断点污染技术指标。

## 设计原则

比亚迪属于高波动成长股，不能只用低估值或股息框架处理。买点更强调趋势仍在时的高质量回调，卖点更强调趋势破位、放量派发和动能恶化。

核心判断顺序：

1. 先判断长期趋势：250 日均线和 120 日均线。
2. 再判断回调质量：离 60/120 日均线的距离、近 60/120 日回撤。
3. 再判断修复动能：20 日均线、MACD histogram、KDJ。
4. 最后判断风险：高波动、派发日、跌破年线、深回撤。

## 买入评分

满分 100，实际由五类信号组成：

| 模块 | 权重 | 解释 |
|---|---:|---|
| 趋势 | 25 | 站上 250/120 日均线、年线向上、BBI 强于 60 日线 |
| 回调质量 | 25 | 从 60 日高点回撤但未破坏结构，靠近 60/120 日均线 |
| 动能修复 | 20 | 重新站上 20 日线、MACD 改善、KDJ 修复 |
| 成交量 | 15 | 温和放量、上涨日放量、近 10 日派发少 |
| 风险过滤 | 15 | 年线距离、120 日回撤、ATR 波动、派发风险 |

买入阈值：

| 条件 | 动作 |
|---|---|
| `buy_score >= 75` 且 `sell_score < 45` | 买入/回补 |
| `buy_score >= 62` 且 `sell_score < 55` | 小幅回补 |
| `buy_score >= 50` 且 `sell_score < 60` | 持有观察 |
| 其他 | 防守等待 |

## 卖出评分

卖出分同样满分 100：

| 模块 | 权重 | 解释 |
|---|---:|---|
| 趋势破坏 | 30 | 跌破 60/120/250 日均线，BBI 弱于 60 日线 |
| 过热 | 20 | 远离 20/60 日均线，RSI/KDJ 极端 |
| 放量派发 | 20 | 放量阴线、收盘靠近低位、近 10 日派发集中 |
| 动能恶化 | 20 | MACD 走弱、KDJ 死叉、20 日线斜率转弱 |
| 止损风险 | 10 | 120 日深回撤或 ATR 波动过高 |

卖出阈值：

| 条件 | 动作 |
|---|---|
| `sell_score >= 85` | 清仓/退出 |
| `sell_score >= 70` | 大幅降仓 |
| `sell_score >= 55` 且 `buy_score < 65` | 减机动仓 |

## 仓位纪律

`target_position_pct` 是本策略对单票账户的仓位建议，不等同于全账户建议。若比亚迪只是组合中的一只股票，应再乘以组合层面的单票上限。

关键纪律：

1. 跌破年线且年线斜率向下时，目标仓位自动封顶 25%。
2. `sell_score >= 70` 时，目标仓位封顶 30%。
3. `sell_score >= 85` 时，目标仓位降为 0。
4. 重仓账户如果当前仓位高于目标仓位 20 个百分点以上，优先减机动仓或高成本仓。
5. 只有 `buy_score >= 75` 且 `sell_score < 45` 时，才允许重新回到重仓区。

## 风险边界

这是规则化交易研究，不构成投资建议。比亚迪受汽车销量、价格战、出口政策、电池业务、智能化进展、汇率与市场风险偏好影响明显，策略只处理价格和成交量层面的持仓纪律，不能替代基本面事件跟踪。
