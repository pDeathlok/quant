# 持仓股次日涨跌事件概率模型

目标是识别少量高概率事件，供后续持仓分析与正T/反T研究使用。允许没有信号，不设置每日 Top K，不按固定卖出规则的收益选择模型。输出是事件概率，成交顺序与执行效果另行验证。

## 当前有效标签

用户明确：盘中下跌不作为预测目标；下跌关注次日开盘与收盘，上涨关注次日开盘、盘中最高价与收盘。五类事件分别设置 1%、2%、3% 阈值，共15个标签：

|类别|目标名|事件定义|
|---|---|---|
|开盘上涨|open_up1/2/3|次日开盘相对T收盘上涨至少1%/2%/3%|
|开盘下跌|open_down1/2/3|次日开盘相对T收盘下跌至少1%/2%/3%|
|盘中上涨|high_up1/2/3|次日最高价相对T收盘上涨至少1%/2%/3%|
|收盘上涨|close_up1/2/3|次日收盘相对T收盘上涨至少1%/2%/3%|
|收盘下跌|close_down1/2/3|次日收盘相对T收盘下跌至少1%/2%/3%|

`low_down*` 标签与旧的双向盘中波动输出已删除。前一轮包含盘中下跌的报告仅作历史实验留存；其82.6%的盘中跌幅命中率不属于当前有效目标。T日本身的低点、反弹、下影等仍可作为预测特征，删除次日低点标签不等于删除当日价格形态信息。

按用户指定，以T日收盘与全天量价作为14:30截面代理。所有百分比相对T日收盘，不是相对次日开盘。盘中上涨仅表示达到过该价位，不表示在最高点成交。开盘下跌和随后盘中上涨可以同时发生；同一观察时点的上涨和下跌事件互斥。

## 数据与特征

使用既有尾盘研究数据集的历史策略池并集，约124.7万条股票日记录。短线按历史筛选结果，长线与好股票按历史规则及快照重建；当前自选池不倒灌历史。标签缺失、停牌或除权导致无法可靠对齐的样本不当作负样本。持仓分析不套用原先“当日是否允许新买入”的筛选。

三组使用相同样本、日期划分、模型参数和标签定义：

|组别|内容|初轮准入特征数|
|---|---|---:|
|lag1|T−1因子、历史量价统计和共用池身份|161|
|t0_base|加T日量价、换手、跳空、振幅、影线、候选池相对表现|193|
|t0_extended|再加18项T日衍生特征|211|

新增特征包括实体占振幅、下影占比、盘中高低偏移、跳空反转与回补、VWAP偏离相对振幅、单位换手价格变化、换手增量、短长量比差、放量实体、振幅扩张、涨跌异常、收盘位置/回落与放量交互、换手与振幅交互。异常幅度缩放项使用历史跳空标准差。候选池广度不称为全市场广度。

池身份在三组间共用，因此lag1是控制池身份后的历史特征基线，不代表筛池本身没有使用当日信息。特征按前缀准入，不读取次日目标。

## 验证协议

分别训练HistGradientBoostingClassifier，按日期逆样本量加权；2024拟合、2025上半年isotonic校准、2025下半年选择特征组与阈值，2026确认。2026已用于前序研究，因此是研究确认期，不是全新盲测。

预设概率阈值0.50/0.60/0.70/0.75/0.80/0.85/0.90/0.95。候选需同时满足命中率≥80%、相对基础发生率提升≥1.2倍、至少50条且20个日期，以及五交易日区块bootstrap的命中率90%区间下沿≥70%。满足者选择覆盖率最高阈值。特征组按支持事件数、合格覆盖率总和、平均Brier skill依次选择，不按确认期重调阈值。

验证期有支持事件时，以截至2025的样本扩展训练、2026上半年校准、2026下半年复验同一组和阈值。报告各阶段，不把单一阶段合格宣称为跨期稳定。区块区间是探索性估计，不是多重搜索调整后的保证。

概率一致性规则：每类3%概率≤2%≤1%；开盘/收盘上涨概率≤对应盘中上涨概率；同一时点上涨与下跌概率和≤1。规则在选择、确认、最新输出中一致应用。为保持各档嵌套，同一观察时点的互斥修正对各档使用共同缩放系数。
