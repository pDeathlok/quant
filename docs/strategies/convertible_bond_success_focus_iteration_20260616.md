# 可转债成功率优先迭代记录

日期：2026-06-16

## 目标调整

本轮不再把年化 10% 作为硬约束，核心目标调整为：

- 提高闭合持仓交易胜率。
- 提高单笔平均收益和利润因子。
- 接受低交易频率、低平均仓位和较长空仓期。
- 重点观察 2024 年以来，同时用 2020 年以来检验稳定性。

## 新增诊断口径

`HoldingGridStrategy` 回测新增完整持仓生命周期记录：

- `position_trades.csv`：记录每个标的从首次建仓到退出或期末仍持有的收益。
- `closed_position_trades`：已退出持仓笔数。
- `position_win_rate`：已退出持仓胜率。
- `position_profit_factor`：已退出持仓利润因子；无亏损时为空值。
- `average_position_return` / `median_position_return`：已退出持仓平均/中位收益。
- `average_holding_days`：平均持仓天数。

这比原来的订单换手次数更贴近“这套策略买进去之后到底赚不赚钱”。

## 成功率优先参数

新增快速迭代脚本：

`scripts/research/iterate_convertible_bond_success_focus.py`

本轮只跑 4 组低位策略，复权频率为周度/月度，窗口为 2020+ 和 2024+：

- `success_strict_block`：更严格的低价、低溢价、低双低，弱市完全禁止新开仓。
- `success_balanced_block`：样本量和确定性折中，弱市禁止新开仓。
- `success_balanced_scaled`：弱市只缩小新仓，不完全禁入，收益弹性更好。
- `success_deep_value`：极深低位，交易极少，胜率高但资金利用率低。

## Case 观察

`success_balanced_block` 月度版在 2024+ 的 8 笔闭合交易全部盈利，平均持仓约 205 天，平均收益约 12%。截至 2026-06-15 仍有 3 笔未平仓：

- `110073.SH`：110.383 建仓，期末 106.786，浮亏 -3.26%。
- `128129.SZ`：107.898 建仓，期末 107.629，浮亏 -0.25%。
- `128127.SZ`：113.144 建仓，期末 114.497，浮盈 1.20%。

2020+ 复盘显示，亏损主要集中在 2024 年弱势阶段以前已经持有的老仓，典型亏损在 -7% 到 -15%。这说明“禁止弱市新开仓”能改善新仓质量，但还不能完全解决老仓在弱市中的退出问题。

## 当前结论

主推方向：

1. 以 `success_balanced_block` 月度版作为“确定性低位建仓”的主策略：少交易、胜率高、回撤低。
2. 以 `success_balanced_scaled` 月度版作为收益增强版本：允许弱市小仓参与，牺牲部分回撤换更高资金利用率。
3. 不建议用周度高频网格作为主线：样本量更多，但单笔中位收益和胜率明显下降。

下一轮优化重点：

- 对老仓增加更细的风险退出：比如市场转弱后若价格跌破买入价且双低优势消失，分批减仓。
- 接入正股趋势确认：只在正股 20/60 日趋势不弱时买入，过滤“债低但股继续下跌”的陷阱。
- 对仍持仓浮亏 case 做专项拆解，判断是应等待、降仓还是止损。
