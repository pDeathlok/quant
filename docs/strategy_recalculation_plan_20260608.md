# 复权口径修复与策略重算计划

更新时间：2026-06-08

## 问题

在 `605128.SH 上海沿浦` 的 SUPER_B1 信号检查中发现，项目计算的 2026-06-05 日线 J 值为 -10.91，而外部行情软件显示 J 值在 20 附近。

核查后确认根因不是 KDJ 公式本身，而是输入价格序列未做连续化处理：

- 2026-06-01 收盘价为 34.70。
- 2026-06-02 `pre_close` 为 23.15，收盘价为 23.40，`pct_chg` 为 +1.0799%。
- 这说明中间存在除权/复权断点；如果直接用未复权 OHLC 计算滚动 KDJ，会把除权断点误判为真实大跌。

## 已修复

- 项目变量库新增连续价格处理：用 `pre_close / 前一日 close` 自动识别除权断点，并把历史 OHLC 调整到当前价格口径后再计算滚动价格指标。
- 日线、周线、月线 KDJ 已改为基于连续 OHLC 计算。
- BBI、MA60、MACD 等项目变量库里的价格滚动指标已改为基于连续 close 计算。
- B1/B2/B3/SB1/SUPER_B1 规则判断已改为使用连续 OHLC，展示价格仍保留原始行情价格。
- 扩展策略扫描里的 KDJ、BBI、均线等指标已改为使用连续 OHLC。
- B1 family 候选缓存已重建；`605128.SH` 在 2026-06-05 不再命中 SUPER_B1。
- 修正了 B1 family 回测表的 `raw_trades` 统计口径：改为每个 split 自己的原始交易数，而不是全 split 总数。

## 影响范围

需要重新计算的内容：

- 全市场项目变量库。
- B1 / B2 / B3 / SB1 / SUPER_B1 规则回测。
- 扩展策略规则回测。
- 所有使用 KDJ、BBI、MA、MACD、布林、ATR、价格形态、未来收益标签的模型训练。
- 前端策略股票池快照。

相对不直接受影响的内容：

- 纯成交量字段。
- 财务字段。
- 市值、换手率等非滚动价格指标。

但由于策略和模型通常会混合使用价格指标，正式结论仍应整体重算后再确认。

## 重算顺序

1. 重建全市场日线派生变量，确认 KDJ/BBI/MACD 等价格指标使用连续价格口径。
2. 重建 B1 family 候选缓存。
3. 重跑 B1 / B2 / B3 / SB1 / SUPER_B1 规则回测，并更新 playbook。
4. 重跑扩展策略规则回测，并更新 playbook。
5. 重训 B1 模型和各扩展策略模型。
6. 重跑模型分买入过滤 + 卖出组合回测。
7. 刷新 MySQL 中的策略股票池快照。
8. 前端仅展示新口径下的股票池和 OOT 指标。

## 当前状态

当前已完成代码修复、单票验证、B1 family 候选缓存重建和前端派生快照清理。

旧模型、旧回测报告、旧 playbook 仍保留用于追溯，但在完成全量重算前，不应继续作为正式策略结论使用。
