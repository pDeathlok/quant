# AKShare 接口速查表

## 核心接口

| 接口 | 用途 | 参数 | 示例 |
|------|------|------|------|
| `stock_zh_a_hist()` | 股票历史行情 | `symbol`, `start_date`, `end_date`, `adjust` | `ak.stock_zh_a_hist("600000", "20230101", "20231231", "qfq")` |
| `stock_yjbb_em()` | 业绩报表（推荐） | `date` (YYYYMMDD) | `ak.stock_yjbb_em("20241231")` |
| `stock_zcfz_em()` | 资产负债表 | `date` (YYYYMMDD) | `ak.stock_zcfz_em("20241231")` |
| `index_zh_a_hist()` | 指数数据 | `symbol`, `start_date`, `end_date` | `ak.index_zh_a_hist("sh000300", "20230101", "20231231")` |

## 业绩报表关键字段

| 字段 | 因子 | 说明 |
|------|------|------|
| `每股收益` | PE | 市盈率计算 |
| `每股净资产` | PB | 市净率计算 |
| `净资产收益率` | ROE | 盈利能力 |
| `营业总收入-同比增长` | 成长 | 营收增长 |
| `净利润-同比增长` | 成长 | 利润增长 |
| `销售毛利率` | 质量 | 盈利质量 |
| `所处行业` | 行业 | 行业分类 |

## 资产负债表关键字段

| 字段 | 因子 | 说明 |
|------|------|------|
| `资产-总资产` | ROA | 总资产收益率 |
| `负债-总负债` | 杠杆 | 负债水平 |
| `资产负债率` | 杠杆 | 财务杠杆 |
| `股东权益合计` | 质量 | 股东权益 |

|------|------|------|
| 纯数字 | 批量查询 | `600000` |

## 因子计算公式

```python
# 价值因子
PE = 每股收益 / 收盘价
PB = 每股净资产 / 收盘价

# 质量因子
ROE = 净资产收益率
ROA = 净利润 / 总资产

# 成长因子
营收增长 = 营业总收入-同比增长
利润增长 = 净利润-同比增长

# 杠杆因子
资产负债率 = 资产负债率
```

## 快速示例

```python
import akshare as ak

# 1. 获取财务数据
df = ak.stock_yjbb_em(date="20241231")

# 2. 筛选股票
stock = df[df["股票代码"] == "600000"]

# 3. 计算因子
stock["pe_ratio"] = stock["每股收益"] / stock["收盘价"]
stock["roe"] = stock["净资产收益率"]

# 4. 获取行业
industry = stock["所处行业"].iloc[0]
```
