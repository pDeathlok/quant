# 政策需求、候选池与业绩验证

## 1. 适用与来源边界

用于默认个股覆盖，以及从政策主线、国产替代、景气变化或上游工具建立候选股票池。已有目标公司时逐项检验，不另造全市场名单；用户只问局部变化时只展开相关环节。

本框架提炼自用户提供的“五条选股原则—卡脖子、涨价、超预期营收—技术择时”材料。估值、预期基准、现金流和失效条件是研究规范的补全，不能冒充原作者的完整交易系统。材料中出现的公司只是历史举例，不是永久白名单；疑似同音名称须重新确认证券身份，不能把推断还原当作作者明确推荐。

研究顺序：

`政策 → 需求/付款方 → 产业链环节 → 公司承接能力 → 销量/售价/收入预期差 → 利润/现金流 → 估值 → 参与、退出与仓位条件`

技术快照可提前计算，最终判断按上述链条组织。公司质量 GQS、估值吸引力与量价确认分别输出，不互相补分。

## 2. 政策如何变成需求

先核验正式文件、规划期、发布日期与可得时点，区分正式纲要、建议、草案、专项政策和市场解读。不固定依赖某一轮五年规划。

每条主线回答：谁需要什么产品，谁采购、谁付款，预算或商业回报来自哪里，何时采购，有哪些准入和交付条件？用“政策支持 → 客户资本开支/采购/消费 → 具体环节 → 上市公司收入”说明路径；缺乏资金、采购或商业场景证据时只列需求线索。

区分扩产、替换、国产份额迁移与价格提升，防止把同一增量重复计入。政策支持不保证利润增长，非政策驱动业务也不应因此被排除。

## 3. 五条原则与候选池

前四条用于选择研究对象，第五条用于独立的参与风险研究；它们是检验维度，不是全行业通用的五项硬门槛。每项记录支持证据、反证、缺口和状态，不凭机构持仓或短期上涨认定产业龙头。

| 原则 | 必须检验 | 常见误判 |
|---|---|---|
| 细分龙头、国产替代与研发进度 | 产品/地域/客户口径下的地位；国产化率口径；研发投入及资本化；样品→验证→认证→批量交付的实际阶段 | 国产化率低不等于公司有能力承接；高研发不等于即将突破 |
| 蓝海、景气、位置低、逻辑强 | 需求空间、竞争扩产、供需周期；股价回撤和估值/盈利预期变化分别衡量 | 跌得多不等于便宜；蓝海不保证不会迅速拥挤 |
| 财报与未来收入 | 订单质量、排产、产能/良率、交付、验收、收入确认及利润现金流 | 框架协议不等于确定订单；订单不等于收入，收入不等于利润 |
| 上游“卖铲子” | 买方和交易标的；产品是否必需；供应商稀缺性、替代与认证壁垒；价值量和议价权 | 上游不天然更好；客户集中、价格竞争、技术替代可能抵消下游增长 |
| 技术择时与仓位 | 可复算信号、周期、流动性、波动、风险预算及失效条件 | 放量不证明机构买入；不明公式的指标不能成为确定指令 |

“机构认可”仅作独立辅助：持仓须记录披露滞后及报告期，资金净流入须说明供应商估算定义；成交量不能识别资金身份。

候选池采用“进入深研 / 待验证 / 排除本轮”状态，说明与本轮主线的关系、主要缺口和下一核验动作。“排除本轮”不等于公司质量差；没有份额或产品证据时用“参与者”，不强称龙头。

## 4. 三个业绩验证维度

### 卡脖子：稀缺性与承接能力

核对进口依赖、技术代差、供给约束、客户验证周期和政策作用，再核对公司实际进度与竞争对手。技术进展分别标记研发、样品、验证、小批量和规模销售；禁止将管理层目标当成已完成节点。

传导：`替代需求 → 产品合格及客户验证 → 国产份额提升 → 公司销量/订单增长`。证伪包括验证失败或延期、竞争对手先行、交付或良率不足。禁止把“行业被卡脖子”直接推导为“目标公司受益”。

### 涨价：谁获得价差

区分实际成交价、报价、合同价，区分产品提价、原料上涨、产品组合升级与汇率变化；记录产品规格、区域、期间和成本传导时滞。

用销量、净售价、单位成本和产品组合解释毛利变化。上游原料涨价可能挤压中下游；均价上升也可能只是高成本产品占比增加。观察竞争新增供给、库存和订单是否支持持续性。没有提价不自动排除公司，降价伴随份额和成本改善也可能创造利润。

### 超预期营收：必须给比较基准

对齐同一预测期、主体、币种、合并范围及收入定义，分别列：

- 实际结果或独立预测及其证据时点。
- 对照基准：历史底稿、公司指引、披露前一致预期或具名分析师预测。
- 基准发布/可得时间、样本数量、区间或离散度；披露后修订预测不能倒填为事前预期。
- 差额、差额原因及市场可能已计价的部分。基准为正时可用 `(实际或独立预测－基准)/基准`；基准为零、负数或口径冲突时用绝对差并解释。

“超过旧底稿”与“超过市场预期”分别写；单份研报不能称一致预期。缺乏可信事前基准时只能写“增长/可能存在预期差，尚未验证”，不称已超市场预期。反向估值是条件推演，也不等同观察到的一致预期。

三项分别标记支持、反对、待验证或不适用，不要求同时成立，不预设固定权重；稀缺性或涨价需最终接到可验证的经营贡献。

## 5. 从订单到现金流的复算桥

按产品或分部建立 `收入＝销量×实际净售价`，数量受需求、可用产能、良率和交付约束；服务/软件使用客户数×客单价、订阅量等适用驱动。区分已签合同、框架协议、意向、可取消订单以及客户预测，核对排产、验收、回款条款和履约成本。

继续计算 `收入 → 毛利 → 扣除研发/销售/管理等费用后的经营利润 → 归母/扣非利润 → 经营现金流与自由现金流`。核对并购并表、汇率、低基数和一次性收入，避免把非内生增长归因于国产替代。应收、合同资产、存货或资本开支吞噬现金时，降低兑现判断。

将上述变量接入既有悲观、中性、乐观情景与独立估值；不要另建不一致的“政策目标价”。每个核心驱动附预计兑现期、监测指标、反方和失效条件。

## 6. 技术择时、退出与仓位研究

先遵守 [technical-price-volume.md](technical-price-volume.md) 的点时数据与技术边界。默认完整覆盖只给紧凑观察及失效条件；明确要求交易计划或仓位研究时，再展开条件式方案，不代用户执行交易。

保留原材料的观察思路，但标明不是已验证规则：收盘后检查候选池量价变化；每周复核指定大盘指数相对 **60日** 均线（不是60周线）；持仓研究可观察个股相对MA5/MA10和MACD动量变化。均线跌破或MACD拐头只触发复核，不自动等于止盈或止损。

可复现性门：

- KDJ须明确K、D、J哪条线、窗口、平滑算法、初值和阈值；“KDJ＜14”定义不足，不能擅自解释成J＜14。
- B1、绿转红、活跃市值、砖形图必须取得实际公式、参数、周期与信号生效规则。存在同名项目实现时先检查其语义和用户所指版本，不能仅凭名称认定等价；否则标为未定义并跳过该信号，不阻断基本面研究。
- 量比须区分盘中同时间比较和日终相对均量；倍量须注明比较日/窗口。脚本未实现的指标不可声称已经计算。
- 每个参与、加减仓或退出条件列出观察周期、完整K线时点、触发、失效和复核动作；区分基本面证伪、估值兑现与价格风险，不把它们压成同一个止损价。

仓位研究优先采用风险预算而非凭信号强弱给固定比例。可用 `研究仓位上限＝min(单股暴露上限, 组合单笔风险预算比例÷假设不利波动比例, 流动性上限)` 作情景算术，明确所有输入及依据，并考虑行业相关性、现有持仓、跳空、涨跌停、滑点和交易成本。此公式不保证最大损失；风险阈值未必能成交。

缺少资金、现有暴露、期限或可承受损失时，给变量公式或标明假设的示例，不虚构适合用户的仓位百分比。任何技术参数的胜率或收益结论都需点时、扣费、样本外证据；未验证时只称启发式方案。

## 7. 输出与跨期复盘

候选池最少输出：

`政策/需求与付款方 | 产业链环节 | 公司/代码与实际业务 | 五原则证据摘要 | 卡脖子/涨价/超预期营收状态 | 预期基准 | 反方与缺口 | 候选状态/下一动作 | 来源与时点`

不强行填满长表：Flash可压缩为段落，Standard给紧凑表，Deep展开证据和收入利润桥。对形成投资判断的公司仍执行既有三情景及最低证据门。

个股覆盖将三维验证并入投资论点，收入与预期差桥并入财务段，独立估值与技术/仓位分列。重复分析保持原论点ID，复核技术验证、订单、价差和预期差是否兑现。

沿用 [review-and-learning.md](review-and-learning.md) 的现有归档契约：把本框架证据放入已有证据账本、论点及监测项，完整表与桥保存到报告正文；不要求存储程序尚未支持的新顶层JSON字段，不改写历史记录。
