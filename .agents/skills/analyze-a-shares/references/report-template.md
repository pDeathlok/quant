# A 股研究报告交付契约

先选择交付档位，再使用对应结构。档位只控制篇幅，不降低证据、时点、估值和安全门。

## 交付档位

| 内容 | Flash | Standard（默认） | Deep |
|---|---|---|---|
| 适用 | 单一事件、明确问题、快速更新 | 常规个股分析与完整覆盖 | 深度底稿、历史复盘、系统同行 |
| 截止与证券确认 | 紧凑必填 | 完整快照 | 完整快照与证据账本 |
| 结论、反方、改变条件 | 必填 | 必填 | 必填并展开反证 |
| 三情景 | 要求投资影响/预测/估值时用紧凑表 | 投资分析必填 | 投资分析必填并附输入表 |
| 业务与财务 | 只写变化及相关基线 | 摘要与关键桥 | 完整标准化、质量和治理 |
| 估值 | 要求时展示变化桥或可复算主估值 | 主估值、敏感性和反向估值 | 主估值、交叉估值、完整敏感性与附录 |
| 量价辅助 | 用户要求时或完整覆盖下给 1–3 条观察 | 完整覆盖时紧凑呈现 | 用户要求或完整覆盖时展开 |
| 催化、风险、监测、来源 | 紧凑必填 | 必填 | 必填并附完整来源账本 |

共同硬门：

- 唯一确认证券代码和本次截止时点后，所有档位先加载同标的历史上下文；命中时必须读取最近完整覆盖、最近基线及两者之间的更新报告。
- 命中历史后，不得只列 `baseline_record_id`。至少展示旧截止、旧结论、关键论点和旧三情景，并明确本次维持、强化、弱化、失效、新增或尚待验证的内容。
- Flash 不要求对纯事实更新强行预测、估值或三情景。
- 一旦给出投资倾向、盈利预测或估值判断，必须展示与任务相称的反方、风险和三情景。
- 一旦发布数值目标价，必须通过最低证据门并展示可复算估值桥；Flash 无法容纳时自动升级为 Standard。
- 不得因篇幅省略分析截止、价格时点、关键来源、数据缺口或免责声明。

Flash 建议按以下顺序交付：

1. 截止时点、证券和覆盖范围。
2. 不超过 8 条的新事实或直接答案。
3. 上一基线记录 ID、旧结论和旧预测；首次建档时明确说明。
4. 相对上一基线的预期差，以及论点、认知分类、预测和估值变化。
5. 需要投资判断时给紧凑三情景。
6. 最强反方、风险、下一观察点、来源和新档案记录 ID。

Standard 使用下列主体结构。Deep 在 Standard 基础上展开完整证据账本、模型输入、交叉估值和方法附录。

## 0. 标题

# [公司全称]（[代码.交易所]）A 股投资研究

## 1. 研究快照（Standard/Deep 必填；Flash 紧凑必填）

| 字段 | 内容 |
|---|---|
| 证券 | 公司全称、代码、交易所/板块、证券状态 |
| 基准价格 | 未复权价格、盘中/收盘、精确时点、来源 |
| 市值与股本 | 整体/A 股/自由流通市值口径；A、H 等类别各自价格×股数、FX 及共同时间戳；目标期同权稀释总股数 |
| 最新财务 | 最新审计年报及最新中报/季报的报告期、`published_at`、`available_at` |
| 业务/行业 | 主营、主要分部、采用的行业分类/估值组 |
| 量价数据 | 日线截止与可得时点、来源、复权、成交量单位、宽基/行业基准；不可用时列明缺口 |
| 历史基线 | 最近完整覆盖与 `baseline_record_id`、各自截止和结论、旧置信度、关键论点与三情景摘要；首次建档写“无历史基线” |
| 目标口径 | 人民币每股；目标价是否含股息（默认不含） |
| 数据完整性 | 完整/部分；最重要缺口 |
| 研究置信度 | 高/中/低及一句理由 |

## 2. 结论先行（必填）

用一段话给出：研究倾向（积极/中性/谨慎，不等同个性化买卖建议）、最关键上行驱动、最关键下行风险和置信度。通过最低证据门时同时给中性目标价及相对基准价空间；未通过时明确写“证据不足，暂不提供精确目标价”。

随后列出：

- **市场可能低估/高估的核心变量**：一句话。
- **最强反方观点**：一句话。
- **结论改变条件**：一个可观察阈值或事件。

### 认知更新摘要（存在历史基线或用户要求复盘时必填）

同标的历史查询命中即视为“存在历史基线”，与用户是否使用“复盘”字样无关。本节不得只比较最终目标价；必须覆盖旧论点、情景假设、证伪条件和未解决问题。

| 论点 ID | 旧判断 | 新事实/结果 | 变化分类 | 新状态 | 模型/估值影响 |
|---|---|---|---|---|---|
| P1 |  |  | `new_information` / `prior_error` / `model_limitation` / `noise` / `unresolved` | strengthened / unchanged / weakened / invalidated / new |  |

另列：

- 哪些旧判断得到验证，但可能只是结果正确而非推理正确。
- 哪些旧判断错误，以及当时是否已有足够证据发现。
- 本次仍未解决的问题和降低置信度的原因。
- 迁移记录存在论点 ID 漂移时，另列“旧记录 ID｜旧论点 ID/原文｜新论点 ID｜映射理由”，并同步保存到 `revision.pillar_id_mappings`。

## 3. 三情景价格预期（投资判断、预测或估值任务必填）

按悲观、中性、乐观顺序，不隐藏负面结果：
三情景的叙事、触发、经营假设与证伪条件始终必填；数值目标价及派生的涨跌幅/总回报只在最低证据门通过时必填。未通过时统一写“暂不提供”或“—”，不用无证据点估值或假精确区间替代。发布数值目标价时，每个情景至少列出带期间、单位和来源/假设标记的一项收入或核心 KPI、一项利润率或 ROE、一项现金流/资本结构/稀释项，以及一项估值参数。

Flash 可把“情景叙事与触发、核心经营假设、估值/影响、证伪条件”压缩成四列，但不能删除任何一个情景。纯事实更新且用户未要求投资影响、预测或估值时，本节可省略。

| 情景 | 情景叙事与触发 | 核心经营假设 | 估值方法与关键参数 | 目标价 | 价格涨跌 | 预期股息/股 | 含息总回报 | 概率 |
|---|---|---|---|---:|---:|---:|---:|---:|
| 悲观 |  |  |  | ¥ 或“暂不提供” | % 或“—” | ¥ 或“—” | % 或“—” | 有依据或“不赋概率” |
| 中性 |  |  |  | ¥ 或“暂不提供” | % 或“—” | ¥ 或“—” | % 或“—” |  |
| 乐观 |  |  |  | ¥ 或“暂不提供” | % 或“—” | ¥ 或“—” | % 或“—” |  |

表后必须写：

- 带时区的分析截止、目标日期和基准价格首次可观察时点。
- 目标价不含股息；含息总回报的股息假设。
- 若赋概率，说明依据、是否穷尽结果空间及概率加权值；若不满足条件，禁止显示加权值。
- 最敏感的两个变量及其影响。

## 4. 投资逻辑与反证（投资分析必填）

每个论点使用同一结构：

### 论点 1：[可证伪标题]

- `[事实]` 支持证据及来源。
- `[估算]` 对 KPI、盈利/现金流或 ROE 的传导。
- `[推断]` 为什么市场尚未充分计价；替代解释是什么。
- 催化剂与预计窗口。
- 监测指标、阈值和证伪条件。

写 2–4 个论点。另设“最强反方观点”小节，给出反方证据和对三情景的影响，不把它埋在风险清单中。

## 5. 业务与行业

覆盖：

- 收入/利润如何产生：产品、客户、渠道、地区和分部。
- 竞争优势、持续时间和可被复制/替代的路径。
- 行业供需、竞争、政策、技术和周期位置。
- 关键外部变量及其对收入、成本和资本的弹性。
- 同行选择标准、入选/排除理由和目标公司的差异。

注明单位、累计/单季/TTM、重述和预测来源。“归母净利率”固定为归母净利润/营业收入；“经营现金利润比”默认为合并经营现金流/合并净利润。若辅助使用经营现金流/归母净利润，标注少数股东口径差异并在重大时对账。对银行、保险等用行业 KPI 替换不适用行。

### 质量与资本

- 利润到现金流的桥，重大非经常项和会计判断。

- 实际控制人、关联交易、质押/减持、激励、再融资、转债和潜在稀释。
- 分红、回购、资本开支和并购的历史效果。

## 7. 估值与可复算桥（发布估值判断时必填）

### 主估值

展示公式和全部关键输入，而不是只给结果：

| 输入 | 数值 | 期间/时点 | 来源 | 事实/估算 |
|---|---:|---|---|---|
| 预测指标 |  |  |  |  |
| 目标倍数/折现率 |  |  |  |  |
| 净债务/监管资本等桥接 |  |  |  |  |
| 稀释股数 |  |  |  |  |

给出从经营指标到 EV、普通股权价值和每股价值的算式。复杂 DCF/SOTP 放入紧凑附表。

### 交叉估值

说明第二方法、结果、与主方法差异及为何采用当前权重。若不适用，明确解释，不能默默跳过。

### 敏感性与反向估值

- 显示两个关键变量的矩阵或上下区间。
- 写出当前价格隐含的一个关键增长/利润率/ROE/商品价格/成功概率，并与可实现边界比较。

## 8. 量价与技术辅助（完整覆盖或用户要求时必填）

技术部分独立于基本面估值。Flash/Standard 可只给最有信息量的 1–3 条观察及其窗口、阈值和失效条件；Deep 使用完整表格。数据充分时按 [technical-price-volume.md](technical-price-volume.md) 填写；不足时明确写“量价数据不足，暂不判断”，不得从截图猜数。

先披露：日线截止、`last_bar_available_at`、数据源、价格复权及锚点、成交量单位、公司行动、样本长度，以及宽基/行业基准。

| 维度 | 可复核观察 | 指标/窗口/阈值 | 辅助解释与失效条件 |
|---|---|---|---|
| 相对强弱 |  | 个股与宽基/行业 20/60 日收益 |  |
| 趋势与位置 |  | MA20/60/120、斜率、60 日位置/回撤 |  |
| 量价配合 |  | 5 日价格变化、近5日/此前20日量比 |  |
| 关键量价事件 |  | 放量突破/破位、放量方向 K、缩量回撤 |  |
| 动量与风险尺度 |  | MACD(12,26,9)、ATR14、20日实现波动 |  |

表后给出：

- **技术辅助结论**：建设性/中性或混合/谨慎，并列具体证据。
- **与基本面的关系**：一致或冲突；冲突时列出未知事件、预期差、市场 beta、拥挤或流动性等替代解释。
- **观察锚**：2–4 个价量位置、触发事件和失效条件；称为观察锚，不承诺支撑/压力必然有效。
- **边界**：技术信号不直接改变盈利、估值输入、目标价或无依据的情景概率，不构成交易指令。

## 11. 最低证据不足时的替代输出

若不能通过 `<skill-dir>/SKILL.md` 的最低证据门，不填虚构数字，改用：

1. 已确认的标的、事实和时点。
2. 缺失/冲突的数据及已尝试来源。
3. 可用的投资逻辑草案和反方观点。
4. 三情景的定性触发与估值公式（目标价写“暂不提供”）。
5. 数据充分时给独立量价辅助观察；不足时列 OHLCV、复权、基准和可得时点缺口。
6. 补齐数据清单和下一步计算方法。
7. 明示“证据不足，暂不提供精确目标价”。
