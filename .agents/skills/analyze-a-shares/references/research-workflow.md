## 1. 标的与研究时点

先建立证券身份卡：公司全称、统一社会信用主体、证券代码、交易所、板块、上市日、风险警示/停牌状态、实际控制人、A/H 或其他上市地、主要业务及报告币种。

记录研究配置：

| 字段 | 要求 |
|---|---|
| 分析截止 | ISO 8601 日期时间和时区；盘中研究精确到分钟或秒 |
| 基准价格 | 原始未复权价格、首次可观察时间、来源；历史收益另写复权口径 |
| 目标期 | 明确目标日期；默认约 12 个月，不写模糊“未来” |
| 财务可得集 | 最新年报、最新中报/季报的报告期、`published_at` 和 `available_at` |
| 币种/单位 | 默认人民币；原始报表单位和转换系数 |
| 股本 | 总股本、A 股流通股、加权平均股数、稀释后股数 |
| 研究边界 | 未覆盖的业务、地区、数据和付费资料 |

## 2. 数据收集清单

### 法定披露

- 最近 3–5 年年报、最近 4–8 个季度或可得累计期。
- 最新审计报告、关键审计事项、内部控制意见、会计政策变化及重述。
- 最新业绩预告/快报、问询回复、更正、监管措施和处罚。
- 重大合同、并购/处置、诉讼、担保、关联交易、资金占用和对外财务资助。
- 分红、回购、增发、配股、可转债、股权激励、限售解禁、股东减持及质押。

### 业务与行业

- 产品/服务、客户、渠道、地域和业务分部收入及利润。
- 销量、价格、市场份额、产能/利用率、订单/合同负债、单位成本等行业 KPI。
- 行业供需、竞争格局、政策、技术替代和上下游议价权。
- 原材料、能源、运费、汇率、利率、税率等外部变量。

### 市场与预期

- 当前与历史估值、行业/指数估值、可比公司同日估值。
- 一致预期的样本数、截止日、均值/中位数/区间和近期修订方向。
- 价格表现、成交额、自由流通市值、停牌和涨跌停造成的流动性约束。技术指标只能作辅助，不得替代基本面目标价。
- 至少 60 日、优选 120–250 日的完整日线 OHLCV，以及同期宽基和行业指数。保存价格复权、复权锚、成交量单位、公司行动、最后 K 线可得时点和缺失区间。

## 3. 财务标准化

### 期间和累计口径

A 股利润表和现金流量表的中报、前三季度通常为年初至报告期末累计值。按同一会计年度还原：

```text
Q1 = Q1累计
Q2 = H1累计 - Q1累计
Q3 = 前三季度累计 - H1累计
Q4 = 全年累计 - 前三季度累计
```

使用 `<skill-dir>/scripts/derive_single_quarter.py` 复算。资产负债表为期末时点数，不做相减或四季相加，除非明确计算变动。

脚本输入示例（数值必须使用同一单位和合并口径）：

```json
{
  "year": 2025,
  "unit": "人民币百万元",
  "metrics": {
    "营业收入": {"q1": 100, "h1": 230, "q3_ytd": 390, "fy": 580},
    "归母净利润": {"q1": 12, "h1": 25, "q3_ytd": 20, "fy": 38}
  }
}
```

运行 `python3 <skill-dir>/scripts/derive_single_quarter.py input.json --format markdown`。缺少累计节点时脚本只返回可推导季度并明确警告，不填零。

滚动十二个月的流量指标：

```text
TTM = 最近完整年度 + 本年最新累计 - 上年同期累计
```

每个组成项必须属于相同合并口径。不能用尚未披露的季度补齐 TTM。

### 单位、币种和重述

- 把元、千元、万元、百万元、亿元转换到一个显示单位，并保留原始单位。
- 对外币业务区分交易汇率、平均汇率和期末汇率；不要把汇兑变化误判成经营增长。
- 若公司重述比较期，主分析用最新重述口径，并在历史时点研究中保留当时原值。
- 对并表范围变化做同口径或备考调整；无法调整时不要直接比较增长率。

### 每股和股本

- 历史 EPS 使用报告披露的加权平均股数；目标价使用目标期合理的稀释后股数。
- 建立股本桥：期初股本 + 增发/转股/期权/限制性股票 - 回购注销 = 期末/目标股本。
- A/H 或多类别公司计算**当前整体市值**时按同一可比时点逐类换算：`A价(CNY/股)×A股数 + H价(HKD/股)×H股数×汇率(CNY/HKD) + 其他类别价(本币/股)×股数×汇率(CNY/本币)`。分别列示每类股份的价格、股数、汇率与时间戳；各类价格或汇率不同步时不得伪称精确整体市值。
- 计算**内在整体股权价值**时使用全部同权稀释股数；整体价值除以全部同权股数得到同权每股价值，再以人民币表达 A 股目标价。股份权利不同则分别估值。
- 市值口径注明整体市值、A 股总市值或 A 股自由流通市值；非金融公司的 EV 从当前整体股权市值出发，不能只用 A 股流通市值。

### 关键公式

```text
收入增长 = 本期收入 / 同口径上期收入 - 1
毛利率 = (营业收入 - 营业成本) / 营业收入
经营利润率 = 经营利润 / 营业收入
归母净利率 = 归母净利润 / 营业收入
ROE = 归母净利润 / 平均归母权益
ROIC = 税后经营利润 / 平均投入资本
净负债 = 有息债务 - 可自由支配现金及现金等价物
自由现金流（简化） = 经营现金流 - 资本开支
经营现金利润比 = 经营现金流 / 合并净利润
```

说明公式调整。若用经营现金流/归母净利润作辅助指标，必须标注少数股东口径差异并在重大时对账。受限资金、客户备付金、预售监管资金或经营必需现金通常不能全部冲减债务。

## 4. 经营与财务质量

### 拆分增长

优先把收入拆成 `销量 × 单价 × 产品/渠道/地域结构`，再把利润拆成毛利、费用、税率、少数股东和非经常项。不要满足于“营收增长、利润增长”的描述。

对未来 1–3 年建立驱动模型：

- 需求：客户数、渗透率、市场容量、更新周期、政策配额。
- 供给：产能、利用率、良率、瓶颈、交付和竞争新增产能。
- 定价：标价、折扣、产品组合、汇率和原材料联动。
- 成本：单位材料、人工、能源、运输、折旧和规模效应。
- 再投资：资本开支、研发、营运资金和并购。

### 利润质量检查

至少检查：

- 归母与扣非归母差异及持续性。
- 经营现金流与利润背离；应收、票据、合同资产、存货、预付款和应付变化。
- 政府补助、公允价值、资产处置、债务重组、投资收益和减值。
- 研发资本化、利息资本化、收入确认、渠道压货、退货与质保准备。
- 商誉、无形资产、在建工程、长期股权投资和其他应收款的异常增长。
- 审计意见、关键审计事项、审计师更换、财务负责人变化和年报问询。

单一红旗不是舞弊结论。写成“观察 → 可能解释 → 需要的验证 → 对估值的影响”。

### 资产负债表与生存能力

- 列出短期债务、到期结构、利息覆盖、担保、质押、受限现金和未确认承诺。
- 对高杠杆公司做融资可得性、再融资成本、契约和稀释压力测试。
- 对负净资产、持续亏损、审计非标、风险警示或退市指标公司，先评估持续经营和残值，再谈盈利倍数。

## 5. A 股治理和资本结构覆盖

### 必查项目

- 实际控制人、国资层级、一致行动人和控制权稳定性。
- 关联销售/采购、关联担保、资金占用、同业竞争和资产注入/剥离。
- 大股东质押、减持计划、司法冻结、限售解禁和员工持股。
- 再融资、可转债转股价/下修、股权激励授予/解锁条件和潜在稀释。
- 分红能力、分红政策、回购目的、资本开支纪律和历史并购回报。
- ST/*ST、退市风险、停复牌、监管问询和处罚。

### 国企覆盖层

不要把“国企”自动等同低风险或资产注入。分别评估政策任务、预算软约束、关联交易、资本回报考核、分红、同业整合、母公司资产质量和少数股东利益。

### 交易制度

只有当交易机制影响结论时才展开，并在分析日从交易所核实现行规则。板块、上市前若干日、风险警示和退市整理期的涨跌幅/交易安排可能不同且会修订，禁止写死永久规则。

## 6. 行业与同行

### 行业定义

同时记录：公司披露的业务分部、官方/指数行业分类、用于估值的经济性分组。若三者不同，解释为什么估值同行以业务驱动为准。

### 同行选择

先定义筛选标准，再选公司：

- 收入与利润驱动相似。
- 商业模式、资本强度和会计口径相似。
- 增长、利润率、ROE/ROIC、周期位置和杠杆可比。
- 监管、地区、客户结构和规模差异可解释。

优先 4–8 家有足够数据的可比公司。展示每家入选/排除理由。用中位数抵抗极值，但不能在看到估值结果后为迎合目标价更换同行。

统一估值日和预测期。例如所有 forward P/E 都使用同一财年或未来十二个月，不把某公司的 TTM 与另一公司的 FY2 混合。

## 7. 量价与技术辅助

完整覆盖按 [technical-price-volume.md](technical-price-volume.md) 给出紧凑辅助层：

1. 先比较宽基、行业与个股的 20/60 日表现，区分市场 beta、行业共振和个股独立强弱。
2. 检查 MA20/60/120、斜率、阶段高低点和距高点回撤；均线缠绕时降低趋势判断权重。
3. 用同一窗口判断价涨量增、价涨量缩、价跌量增或价跌量缩；缩量回撤必须有前置放量确认且趋势未明显破坏。
4. 标记放量突破/破位、放量方向 K、冲高回落等关键观察事件，但不把成交量解释为已证实的资金身份。
5. 用 MACD `(12,26,9)`、ATR14 和 20 日实现波动作二级确认与风险尺度，不由金叉/死叉直接生成买卖结论。
6. 量价结论只影响置信度、市场确认和监测优先级，不直接改变经营预测、估值参数、目标价或无依据概率。

若数据契约满足，可运行 `<skill-dir>/scripts/price_volume_snapshot.py` 复算；报告必须展示数据截止、最后 K 线可得时点、复权、成交量单位、阈值和局限。数据不足时不从截图猜数。

## 8. 投资逻辑和反方观点

### 论点模板

每个论点支柱写成：

```text
观点：市场对什么定价不足/过度？
证据：哪些一手事实和数据支持？
传导：驱动如何改变 KPI、盈利/现金流和估值？
时间：何时可能体现？
催化剂：什么公开事件让市场重新定价？
反方：最强替代解释是什么？
证伪：哪个可观察阈值触发下调/放弃？
```

“好公司”不等于“好股票”。明确区分业务质量、盈利预期差和当前价格隐含预期。

### 反方搜索

主动查找：监管问询、风险提示、减持、客户/供应商问题、竞争对手扩产、行业价格下跌、审计异常及历史承诺未兑现。把最强反方观点放入结论附近，不埋在长风险列表末尾。

## 9. 置信度与完成检查

用高/中/低置信度，不做伪精确评分：

- **高**：关键输入来自一手且口径一致；业务可预测；两种估值相互支持；反方证据已覆盖。
- **中**：少量关键输入依赖二手估计、周期位置或政策判断；敏感性较高。
- **低**：数据缺失/冲突、早期业务、困境融资、重大二元事件或模型高度依赖终值。

完成前确认：

- [ ] 标的、截止日、价格、目标日、币种、复权和股本口径明确。
- [ ] 最新法定披露及期后公告已读，关键数字可追溯。
- [ ] 单季、TTM、重述、非经常项和稀释处理正确。
- [ ] 同行选择和估值期一致，没有事后挑选。
- [ ] 量价辅助使用完整点时数据、明确复权与基准；技术结论未替代基本面估值。
- [ ] 投资逻辑包含传导、反方、监测和证伪。
- [ ] 三情景经营假设始终完整；通过最低证据门时目标价可复算，否则条件、公式和数据缺口完整。
- [ ] 数据缺口、方法局限和免责声明显著。
