## 1. 定位与边界

把技术分析限定为**价格行为、资金参与度和市场风险的辅助观察层**。它回答：

- 市场目前是否在确认、质疑或尚未交易基本面逻辑？
- 价格处于上升、下降还是震荡结构？成交量是在确认还是背离？
- 哪些可观察价位或量价事件值得后续监测？
- 当前波动、流动性和拥挤程度是否放大执行风险？

不得把技术信号写成公司内在价值，不得仅凭形态上调盈利、估值倍数或情景概率，不得把“支撑位”“主力成本”“吸筹/出货”写成已证实事实。除非有经样本外验证的策略统计，否则只标为启发式观察，不声称胜率。

完整基本面覆盖默认给一个紧凑的日线量价辅助层。只有用户明确要求交易周期分析时才扩展周线或更短周期；长期研究默认不使用分钟线制造精度。

本框架在设计时参考了 `zettaranc-skill` 中关于关键放量 K、放量异动后的缩量回撤、趋势线和高位放量阴线的思想，已抽象为一般化、可复算的量价规则；运行时不依赖该项目，也不继承其中固定买卖口令或未经本任务验证的阈值。

## 2. 数据契约与时点

至少准备：

| 字段 | 要求 |
|---|---|
| 标的 | 已核验的六位代码和交易所 |
| 截止时点 | 带时区的 `analysis_cutoff` |
| K 线可得时点 | 最后一根完整 K 线的 `last_bar_available_at`，必须不晚于截止时点 |
| 日线 | 至少 60 个交易日，优选 120–250 日的开、高、低、收、成交量 |
| 价格口径 | 未复权/前复权/后复权及复权基准日；整段序列必须一致 |
| 成交量口径 | 股/手及供应商定义；同一序列不得换单位 |
| 公司行动 | 分红、送转、拆并股、配股、停复牌和异常交易状态 |
| 基准 | 同期宽基指数及适用行业指数，使用相同频率、截止日和收益口径 |
| 来源 | 数据供应商、接口/页面、拉取时点和缺失区间 |

执行以下时点规则：

1. 日线全日 OHLCV 只有在收盘且数据源已发布后才算可得；盘中不得使用尚未完成的当日全日成交量。
2. 历史时点研究不得直接使用以今天为锚、含后来公司行动的前复权序列。使用当时未复权序列并处理截止日前已知公司行动，或使用明确锚定在历史截止日的点时复权序列。
3. 将停牌日、零成交、涨跌停封单、上市初期无涨跌幅限制等状态单列；它们会使成交量和波动指标失真。
4. 不把不同供应商的成交量单位、复权算法或缺失日序列直接拼接。
5. 数据少于 60 根日线时只报告缺口，不输出完整趋势结论；少于 120 根时不声称已观察长期均线结构。

## 3. 分析顺序

### 3.1 市场与相对强弱

先判断同期宽基和行业指数的趋势、波动与成交活跃度，再看个股。至少比较 20 日和 60 日收益：

```text
个股相对强弱 = 个股区间收益 - 基准区间收益
```

区分“个股独立走强”“行业共振”“仅由大盘 beta 推动”。基准不同会改变结论，必须说明选择理由。

### 3.2 趋势结构

优先使用少量、可解释指标：

- 收盘价相对 MA20、MA60、MA120 的位置。
- MA20 的短期斜率及 MA20/MA60/MA120 排列。
- 20/60 日区间高低点、距高点回撤和区间位置。
- 趋势延续是否伴随量能，还是价格上涨但参与度下降。

将结构写成“上升/下降/震荡或混合”，不要由一次均线穿越直接下结论。震荡期均线反复缠绕时主动降低指标权重。

### 3.3 量价状态

用相同窗口的价格变化与成交量趋势形成四象限：

| 价格 | 成交量 | 常见解释 | 必须核对 |
|---|---|---|---|
| 上涨 | 放大 | 参与度确认上涨，也可能是高位换手 | 所处位置、K 线实体、是否突破、次日承接 |
| 上涨 | 收缩 | 抛压较轻或上涨参与度下降 | 趋势阶段、是否接近前高、后续能否补量 |
| 下跌 | 放大 | 抛压/分歧扩大，风险优先 | 是否重大事件、破位、跌停或指数共振 |
| 下跌 | 收缩 | 回撤抛压减弱或流动性枯竭 | 原趋势是否向上、是否有前置放量确认 |

“缩量回撤”只有在此前存在可确认的放量上涨/突破、价格仍守住趋势结构时才具有正面辅助意义；下降趋势中的缩量下跌不能自动解释为见底。

### 3.4 关键放量 K

把显著高于近期均量、实体或振幅较大的 K 线标为“关键观察 K”，记录高点、低点、成交量比和发生位置：

- 放量向上突破：观察后续能否守住突破区及成交量是否有序回落。
- 放量向下破位：作为风险事件，检查基本面消息、融资/减持和市场共振。
- 上涨较多后的放量长阴、长上影或冲高回落：标为分歧/供给增加，不能直接断言“主力出货”。
- 放量上涨后的缩量整理：只有未破坏关键区间且相对基准不恶化时，才标为建设性整理候选。

关键 K 的高低点是观察锚，不是保证有效的支撑或压力。若后续收盘有效穿越且量价结构改变，立即更新锚点。

### 3.5 动量、波动与流动性

- 可用标准 MACD `(12,26,9)` 观察中期动量和零轴位置，但只作二级确认；金叉/死叉不是独立买卖结论。
- 背离只标为“动量未确认价格新高/新低”，需要多个观察点和后续价格确认，不预测精确顶部或底部。
- 用 ATR14/收盘价和 20 日实现波动率描述风险尺度；不同波动股票不能用相同百分比阈值比较。
- 检查成交额、换手率、自由流通市值、停牌和涨跌停。成交量放大不等同资金净流入，更不证明某类投资者身份。

## 4. 量价状态与关键形态

默认启发式参数仅用于生成待核对信号：

| 参数 | 默认起点 | 用途 |
|---|---:|---|
| 放量比 | 当日量/前 20 日均量 ≥ 1.5 | 标记显著参与度变化 |
| 缩量比 | 近 5 日均量/此前 20 日均量 ≤ 0.7 | 标记成交收缩 |
| 突破缓冲 | 0% | 与前 20 日高低点比较；高波动标的应使用 ATR 缓冲 |
| 大实体 | 实体/ATR14 ≥ 0.8 | 标记关键方向 K |
| 均线容忍 | 距 MA20 不低于 -2% | 识别未明显破坏趋势的回撤候选 |

这些不是跨公司永久有效的市场规律。若用于策略判断，必须以标的流动性、波动、板块和市场状态做历史分位校准，并用滚动样本外或留出期验证。报告必须同时展示参数，不得只给信号名称。

至少输出以下观察：

1. 5/20/60 日价格表现和对指数/行业相对强弱。
2. MA20/60/120、斜率和当前价位置。
3. 当日/近 5 日量能相对此前 20 日均量。
4. 20 日价量四象限。
5. 是否出现放量突破、放量破位、放量方向 K 或前置放量后的缩量回撤。
6. ATR、实现波动率、距阶段高点回撤。
7. 数据缺口、复权和公司行动影响。

## 5. 与基本面、估值和三情景的关系

严格分开“价值判断”和“价格行为”：

| 基本面/估值 | 量价结构 | 解释方式 |
|---|---|---|
| 积极且有安全边际 | 建设性 | 市场开始确认；仍按基本面证伪条件监测 |
| 积极且有安全边际 | 谨慎 | 价值与价格背离；检查未知事件、预期差和流动性，不机械下调内在价值 |
| 昂贵或基本面弱 | 建设性 | 动量强但估值风险未消失；不得用上涨证明估值合理 |
| 昂贵或基本面弱 | 谨慎 | 基本面和价格风险共振，突出下行情景与流动性压力 |

技术信号可以：

- 改变结论置信度、风险提示和监测优先级。
- 帮助描述市场是否正在交易某个催化剂或风险。
- 作为三情景的**市场确认指标**，例如“行业指数相对强弱转正且放量突破”。

技术信号不可以：

- 直接改变收入、利润率、现金流、WACC、目标倍数或目标价。
- 在没有统计依据时改变三情景概率。
- 用当前价格上涨反向证明乐观情景已经实现。
- 将短周期图形与 12 个月目标价混为同一时间尺度。

## 6. 输出契约

量价辅助段必须包含：

1. 数据截止、K 线可得时点、来源、频率、复权和成交量口径。
2. 趋势、量价、关键 K、动量/波动、相对强弱五类观察。
3. “建设性/中性或混合/谨慎”的辅助结论及具体证据。
4. 与基本面结论一致或冲突之处；冲突时列出需要核验的替代解释。
5. 2–4 个可观察价量锚点和失效条件。
6. 显著声明：技术分析不改变独立估值，支撑/压力不是确定性价格承诺。

没有完整数据时写“量价数据不足，暂不判断”，列出缺失窗口、复权或可得时点，不从截图猜数。

## 7. 计算脚本

`<skill-dir>/scripts/price_volume_snapshot.py` 接受日线 OHLCV JSON，验证时点、复权、顺序和 OHLC 合法性，并输出可复核的技术快照。脚本只做确定性计算，不抓取行情、不生成买卖指令、不证明统计有效性。

脚本一次只计算一个序列。个股相对宽基/行业强弱必须使用同截止、同复权口径的基准序列另行复算并比较区间收益；没有同步基准时明确写“相对强弱未计算”，不得用大盘印象代替。

运行：

```bash
python3 <skill-dir>/scripts/price_volume_snapshot.py input.json --format markdown
```

输入根字段：`ticker`、`as_of_date`、`analysis_cutoff`、`last_bar_available_at`、`source`、`price_basis`、`volume_unit`、`bars`；复权序列另填 `adjustment_reference_date`。每根 bar 必须有 `date/open/high/low/close/volume`。可在 `thresholds` 显式覆盖默认启发式参数。

## 8. 局限与完成检查

- [ ] 没有未来 K 线、后来公司行动或未完成当日全日成交量进入历史研究。
- [ ] 股票、指数和行业基准使用一致频率、截止日和收益口径。
- [ ] 复权方式、复权锚点、成交量单位和缺失/停牌日已披露。
- [ ] 所有阈值和窗口已展示，没有把启发式信号写成统计胜率。
- [ ] 放量/缩量均相对同一标的自身历史，而非跨标的比较绝对量。
- [ ] 关键 K、支撑/压力只写观察锚和失效条件。
- [ ] 基本面估值与技术辅助结论分列，时间尺度一致。
- [ ] 没有输出个性化交易执行指令或收益承诺。
