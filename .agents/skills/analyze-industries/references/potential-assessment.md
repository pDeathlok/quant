## 1. 潜力的四种量化结果

在评分之前尽量计算：

### 增量收入池

`终点市场收入 - 基准市场收入`

说明数量、ASP、汇率和产品结构分别贡献多少。

### 增量利润池

`终点可持续利润池 - 基准可持续利润池`

利润口径可以是毛利、营业利润、EBITDA 或现金利润，但同一比较表必须一致。

### 国产替代池

`中国需求 × (可实现国产份额 - 当前国产份额)`

这是市场上限。进一步乘以本土供应商可取得价格、利润率和时间兑现系数，形成条件情景。

### 份额迁移池

`目标市场 × 可实现份额变化`

用于技术路线替代、渠道迁移或龙头整合。必须说明份额从谁转向谁及原因。

若无法量化，保留公式、范围和缺口，不用评分替代缺失的市场数据。

证据不足时可以给“补数优先级 1/2/3”，表示下一步研究顺序；不得使用“高/中/低”或“中高”等正式潜力档，以免把待验证假设误读为潜力结论。

## 2. 五维评分

每项 1–5 分，评分必须有节点级证据。

### A. 市场空间

| 分数 | 判断 |
|---:|---|
| 1 | 市场收缩或增量很小，价格下降抵消数量增长 |
| 2 | 低个位数增长，绝对增量有限 |
| 3 | 中等规模或中个位数增长，有明确增量 |
| 4 | 大规模且较快增长，底层驱动可复算 |
| 5 | 巨大增量池、多重驱动且多个方法收敛 |

同时报告当前规模和增量，不让小市场高增速掩盖绝对空间。

### B. 利润池

| 分数 | 判断 |
|---:|---|
| 1 | 结构亏损、资本回报差或利润被持续压缩 |
| 2 | 低利润、强周期或现金转换差 |
| 3 | 利润率和回报中等，价值捕获与行业接近 |
| 4 | 较强定价权、利润增长快于收入、现金良好 |
| 5 | 高质量可持续利润池，增量利润显著且难被上下游拿走 |

### C. 结构质量

| 分数 | 判断 |
|---:|---|
| 1 | 同质化、易扩产、价格战、低切换成本 |
| 2 | 壁垒有限，竞争者多且份额不稳定 |
| 3 | 有一定认证、规模或客户壁垒 |
| 4 | 集中度合理、壁垒可验证、份额较稳定 |
| 5 | 稀缺资源/技术/网络/标准形成持久优势且能转化为 ROIC |

集中度高但受单一买方或监管压价，不应自动高分。

### D. 中国机会

| 分数 | 判断 |
|---:|---|
| 1 | 中国需求小、已高度国产化或本土能力无明显空间 |
| 2 | 有需求但替代空间、技术差距或经济性有限 |
| 3 | 存在明确份额提升、出口或结构升级机会 |
| 4 | 市场大、国产化仍低且本土能力正在商业验证 |
| 5 | 大规模可兑现替代/出口池，关键约束已基本突破 |

该维度不仅看国产化率，还看中国供应商的技术、认证、产能、成本和客户接受。

### E. 兑现确定性

| 分数 | 判断 |
|---:|---|
| 1 | 依赖远期技术、政策或融资，路径高度不确定 |
| 2 | 周期长、验证早期、关键产能或基础设施缺失 |
| 3 | 路径合理但仍有重要执行和时间风险 |
| 4 | 订单、认证、产能或政策已经形成领先证据 |
| 5 | 多个领先指标验证，兑现周期短且约束可控 |

## 3. 默认权重与五档结论

投资研究默认权重：

| 维度 | 权重 |
|---|---:|
| 市场空间 | 25% |
| 利润池 | 25% |
| 结构质量 | 20% |
| 中国机会 | 20% |
| 兑现确定性 | 10% |

标准化：

`潜力分 = (Σ(分项分数 × 权重) - 1) / 4 × 100`

五档：

- `≥80`：高。
- `65–<80`：中高。
- `45–<65`：中。
- `30–<45`：中低。
- `<30`：低。

分档是透明的比较工具，不是统计预测。报告必须同时展示五个分项和置信度。

不同任务应显式改权重：

- 市场进入：提高中国机会、兑现确定性和主体“赢的能力”。
- 供应链安全：提高中国机会、结构质量和瓶颈重要性。
- 全球战略：降低中国机会权重，增加全球竞争位置。
- 成熟周期行业：提高中周期利润池和结构质量。

## 4. 中国机会

将中国机会拆成四条路径：

1. **进口替代**：中国需求由海外供应转向本土供应。
2. **在华替代**：外资在华生产或品牌份额被本土主体替代。
3. **全球份额**：中国企业在海外市场取得份额。
4. **产品升级**：从低价值环节进入高性能、高毛利或关键标准环节。

每条路径检查：

- 当前份额和目标份额分母。
- 技术/质量差距。
- 客户认证和切换周期。
- 有效产能、良率和资本需求。
- 成本优势是否可持续。
- 海外贸易、知识产权和监管风险。
- 替代是否伴随 ASP 或利润率下降。

低国产化率本身不是高潜力证据；有时代表技术不可得、市场太小或客户不愿切换。

## 5. 兑现条件与时间

为高潜节点写：

| 项目 | 内容 |
|---|---|
| 核心驱动 | 可观察的需求、技术、价格或份额变量 |
| 必要条件 | 认证、产能、基础设施、政策或融资 |
| 领先指标 | 能提前验证的订单、良率、库存、招标等 |
| 预计窗口 | 0–1年、1–3年、3–5年或更长 |
| 证伪条件 | 明确阈值、替代路线或事件 |
| 主要受益者 | 节点和参与者证据等级 |

区分：

- **理论空间**：技术或政策完全实现后的上限。
- **可服务空间**：现有产品和地理能覆盖。
- **可兑现空间**：在预测期内结合产能、份额和认证可实现。

## 6. 置信度

置信度单独记录 0–1 或低/中/高：

- 规模证据质量。
- 参与者与份额完整性。
- 利润率和资本回报可比性。
- 预测驱动可观察性。
- 关键技术和政策不确定性。

建议数值映射：

- 高：`0.8–1.0`
- 中：`0.5–<0.8`
- 低：`0–<0.5`

不把置信度直接乘进潜力分，以免把“证据少”误写成“潜力低”。排序时并列显示；低置信度高潜节点应标为“待验证”，而不是稳健首选。

## 7. 排序脚本输入契约

```json
{
  "perspective": "listed_equity",
  "weights": {
    "market_space": 0.25,
    "profit_pool": 0.25,
    "structural_quality": 0.20,
    "china_opportunity": 0.20,
    "realization_certainty": 0.10
  },
  "links": [
    {
      "id": "C1",
      "name": "示例核心部件",
      "scores": {
        "market_space": 4,
        "profit_pool": 5,
        "structural_quality": 4,
        "china_opportunity": 3,
        "realization_certainty": 4
      },
      "confidence": 0.75,
      "evidence_note": "两种规模方法收敛，份额仍有缺口"
    }
  ]
}
```

运行：

```bash
python <skill-dir>/scripts/rank_industry_links.py input.json --format markdown
```

权重必须为非负并至少一项大于零；脚本会归一化。分项必须为 1–5，置信度为 0–1。

## 8. 使用边界

- 不把高增速等同高利润。
- 不把高壁垒等同上市公司能受益。
- 不把低国产化率等同国产替代必然发生。
- 不把规划产能等同可兑现份额。
- 不把潜力分用于精确预测个股回报。
- 不隐藏低分节点；它们可能是产业约束、成本中心或风险来源。
- 若数据不足，先输出待验证假设和补数清单，再决定是否评分。
- 将补数优先级与潜力档使用不同名称和量表，禁止用研究关注度暗示正式潜力排序。
