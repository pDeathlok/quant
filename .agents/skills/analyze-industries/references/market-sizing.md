## 1. 规模词典

| 名称 | 含义 | 常见误用 |
|---|---|---|
| 产能 | 理论或有效生产能力 | 当成实际产量或需求 |
| 产量/出货 | 一定期间生产或交付数量 | 跨渠道重复、未扣内部交易 |
| 装机 | 新增或累计安装数量/功率 | 混用新增与保有量 |
| 表观消费 | 生产 + 进口 - 出口 - 库存变化 | 库存缺失时当实际终端消费 |
| 厂商收入 | 生产商确认的对外收入 | 与渠道和终端销售额相加 |
| 终端销售额 | 终端客户支付金额 | 混入税费、安装与服务 |
| GMV | 平台促成的交易总额 | 当平台净收入 |
| 当前市场 | 当前真实交易规模 | 当所有潜在需求 |
| TAM | 在明确产品、价格和边界下的全部可寻址需求 | 把宏大相邻市场当本市场 |
| SAM | 技术、地区、渠道或监管上可服务部分 | 不说明限制条件 |
| SOM | 特定主体在明确期限可能获得部分 | 用固定百分比拍脑袋 |
| 增量收入池 | 终点市场收入 - 基准市场收入 | 忽略 ASP、汇率和结构变化 |
| 增量利润池 | 增量收入 × 可捕获利润率并考虑份额 | 直接套行业平均毛利 |

报告中的“市场规模”必须替换成表内具体概念。

## 2. 统一口径

每个规模对象建立口径卡：

```text
节点ID：
产品/服务：
包含：
排除：
交易层级：
地理：
基准年：
单位：
币种：
价格基准：
税费/补贴/安装/服务：
生产、消费或收入：
名义或不变价：
```

比较两个来源前逐项对齐。不能对齐时，不放进同一个平均值；应解释它们测量的是不同市场。

涉及多产品时使用互斥分部：

`总规模 = Σ(细分数量_i × 同层ASP_i)`

记录各分部是否有交叉销售或一笔交易同时落入多个标签。

## 3. 当前规模估算

### 自上而下

从官方、协会或有方法报告取得总规模，再按地区、产品、客户或用途拆分。

要求：

- 保存原始定义和覆盖率。
- 避免用母市场 × 随意渗透率。
- 拆分比例和总规模应来自兼容期间。
- 协会会员数据要调整非会员覆盖或明确下限。

### 自下而上

优先使用可审计桥：

#### 量价法

`市场收入 = Σ(需求量_i × ASP_i)`

适合标准化产品。ASP 应与数量处于同一交易层级。

#### 装机价值量

`环节规模 = 新增装机/销量 × 单位系统中该环节价值量`

说明单机价值量是否随技术、规模或价格下降。

#### 产能法

`有效供给价值 = 名义产能 × 有效开工率 × 良率 × ASP`

不能用公告规划产能代替有效产能。

#### 参与者加总

`覆盖收入 = Σ(参与者该节点收入)`

`行业规模 ≈ 覆盖收入 ÷ 参与者覆盖份额`

剔除内部交易、跨节点收入和非目标地区收入。覆盖份额若无法证实，只能给下限或区间。

#### 存量与替换

`年度需求 = 新增需求 + 存量 × 替换率 + 维护/耗材需求`

适合设备、基础设施、订阅续费和后市场。

### 方法选择

关键节点至少使用：

- 一种自上而下 + 一种自下而上；或
- 两种底层独立的自下而上方法。

两个同源第三方报告不算独立方法。

## 4. 中国与全球复核

### 中国供需平衡

标准检查：

`表观消费 = 境内产量 + 进口 - 出口 - 库存增加`

若库存变化未知：

`简化表观消费 = 境内产量 + 进口 - 出口`

必须注明这是近似。对于加工贸易、保税区、转口贸易和产品编码混杂，另做调整。

### 国产化率

先声明分母：

- 按中国需求数量。
- 按中国需求金额。
- 按中国客户采购额。
- 按中国境内生产。

常用公式：

`需求金额国产化率 = 国内供应商面向中国客户收入 ÷ 中国需求金额`

`供应国产化率 = 中国境内本土控制产能/产量 ÷ 中国境内总产能/产量`

二者不可互换。外资在华生产、国内企业海外生产和进口后本地集成需要单独定义。

### 全球复核

- 汇总主要地区时设置“其他地区”并检查合计。
- 汇总主要公司时检查覆盖率和跨区域内部销售。
- 以产量估值时，全球产量应与主要消费行业投入量、库存和损耗大致闭合。
- 全球报告与中国报告基准年不同，先滚动到统一期间再比较。

## 5. 预测与增量池

预测从底层驱动开始：

`需求量 = 潜在单位数 × 渗透率 × 单位配置量 × 替换/使用频率`

`市场收入 = 需求量 × ASP`

驱动可以包括：

- 终端销量或用户数。
- 渗透率和替换周期。
- 单机/单位配置量。
- 产品结构与 ASP。
- 产能投放、利用率、良率和供给约束。
- 政策额度、招标、基础设施、认证与建设周期。

CAGR：

`CAGR = (终值 / 初值)^(1 / 年数) - 1`

增量收入池：

`终点规模 - 基准规模`

增量利润池应使用该节点可持续营业利润、EBITDA、毛利或现金利润口径，并说明为何选用；没有可比利润率时不强算。

国产替代池的简化上限：

`中国需求 × (目标国产份额 - 当前国产份额)`

再乘可实现的本土供应价格或利润率，并考虑认证周期、产能、技术差距和价格下降。它是条件空间，不是收入预测。

### 三情景

围绕相同驱动构建悲观、中性、乐观：

| 驱动 | 悲观 | 中性 | 乐观 |
|---|---:|---:|---:|
| 终端需求 |  |  |  |
| 渗透率/配置量 |  |  |  |
| ASP/产品结构 |  |  |  |
| 有效供给/利用率 |  |  |  |
| 市场规模 |  |  |  |

避免一边假设供给短缺，一边又使用激进销量而不提高价格或新增产能。

## 6. 双重计算与上下游约束

产业链各层收入代表同一价值在不同交易阶段流转，通常不能相加。允许求和的条件：

1. 同一交易层。
2. 同一地理和期间。
3. 同一价格基准。
4. 细分互斥。
5. 已剔除内部交易。

一致性检查：

- 上游投入量 × 转化率 ≈ 下游产量 + 损耗。
- 核心部件出货 ≈ 系统销量 × 单机配置。
- 设备销售与新增产能建设周期相容。
- 存量设备、寿命和替换率能支撑后市场需求。
- 参与者收入汇总不超过同口径行业规模。
- 市占率合计不超过 100%，`其他`项合理。
- 市场规模增长能由数量、价格或组合变化解释。

## 7. 区间和置信度

对同口径估算计算：

- 最小值与最大值。
- 中位数。
- 显式权重下的加权中心。
- 相对分歧：`(最大值 - 最小值) / 中位数`。

默认解释：

- `≤15%`：基本收敛。
- `15%–35%`：存在重要口径或假设差异。
- `>35%`：显著分歧，优先给范围和低置信度。

不要把加权中心称为“真实值”。权重只反映证据质量判断，并在报告中列明。

## 8. 复算脚本输入契约

对单个或多个节点运行：

```json
{
  "markets": [
    {
      "id": "C1",
      "name": "示例核心部件",
      "geography": "China demand",
      "base_year": 2025,
      "unit": "CNY_billion",
      "basis": "manufacturer_revenue",
      "estimates": [
        {"label": "official", "method": "top_down", "value": 100, "weight": 2},
        {"label": "volume_x_asp", "method": "bottom_up", "value": 108, "weight": 1}
      ],
      "forecast": {"end_year": 2030, "end_value": 165, "cagr": 0.105},
      "flow_balance": {
        "production": 120,
        "imports": 15,
        "exports": 30,
        "inventory_increase": 2,
        "stated_demand": 103
      }
    }
  ]
}
```

所有数值共享市场级 `unit`。`forecast.cagr` 使用小数。`flow_balance` 只能在数量或同口径价值可加减时使用。运行：

```bash
python <skill-dir>/scripts/reconcile_market_size.py input.json --format markdown
```

脚本只做输入验证和算术，不判断来源是否独立、口径是否真的兼容，也不自动选择最终报告数字。
